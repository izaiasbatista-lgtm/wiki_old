# Permissões do Radar Exevutivo
![](https://wiki.simeon.com.br/wp-content/uploads/2022/06/Imagens-Engracado-PNG-e-Vetor_-com-Fundo-Transparente-Para-Download-Gratis-_-Pngtree-removebg-preview-e1718048897376-200x300.png)

Neste artigo, vamos explorar as permissões existentes dentro da funcionalidade do Radar Executivo.

**Parametrizar o Radar Executivo:**

Gerenciar Usuário → Permissões Gerais → Parametrização → Planejamento → Radar Executivo.

Essa permissão é essencial para que o usuário tenha a autonomia de personalizar as informações que serão listadas no Radar.

**Visualizar o Radar Executivo:** 

Gerenciar Usuário → Permissões Gerais → Planejamento → Relatórios → Radar Executivo.

Essa permissão é importante para que os usuários possam visualizar as informações configuradas na parametrização.
