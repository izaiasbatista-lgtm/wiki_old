# Entenda sobre os Filtros do Radar de Atividades
**![](https://wiki.simeon.com.br/wp-content/uploads/2023/05/depositphotos_38689733-stock-photo-giraffe.webp)**

Vamos entender sobre os filtros do Radar de Atividades.

1.  **UEN (Unidade Estratégica de Negócio)**:
    
    -   **Filtro**: Este filtro listará apenas as UENs das unidades que se comunicam, mesmo que o usuário tenha a permissão de super usuário no EPA.
    -   **Comportamento**: Mesmo com permissões avançadas, apenas as UENs de unidades que têm comunicação serão exibidas. Isso pode ser para garantir que apenas dados relevantes e atualizados sejam mostrados.
2.  **Data Início e Data Fim**:
    
    -   **Filtro**: Este filtro considerará as datas reais dos módulos.
    -   **Comportamento**: As datas inseridas nos campos de Data Início e Data Fim serão utilizadas para filtrar os dados reais dos módulos, permitindo uma análise de um período específico.  
        A busca vai trazer as atividades que a Data Início Prevista ou que a Data Fim Prevista estejam dentro do intervalo do período especificado.
3.  **Unidade Gerencial Padrão**:
    
    -   **Filtro**: Com base na unidade gerencial padrão, o sistema mostrará as unidades correspondentes listadas abaixo.
    -   **Comportamento**: Dependendo da unidade gerencial selecionada, uma lista das unidades subordinadas ou relacionadas será exibida, facilitando a navegação e gestão de dados.
4.  **Usuário Responsável**:
    
    -   **Filtro**: Este é um filtro opcional para designar ou não um usuário responsável.
    -   **Comportamento**: Permite a escolha de um usuário responsável para as ações ou dados filtrados. Se nenhum usuário for designado, o filtro pode ser ignorado.

### Exemplo de Aplicação:

Suponha que você esteja utilizando um sistema de gestão e quer gerar um relatório baseado nos seguintes critérios:

-   **UEN**: Você seleciona as UENs de unidades que você se comunica.
-   **Data Início e Data Fim**: Define um período específico para analisar os dados reais.
-   **Unidade Gerencial Padrão**: Seleciona uma unidade gerencial padrão para filtrar as unidades relacionadas.
-   **Usuário Responsável**: Escolhe (ou não) um usuário responsável para o relatório.

Este processo permitirá que você obtenha um relatório preciso e relevante, alinhado com as unidades de negócio comunicativas, em um período específico, com a hierarquia correta e, se necessário, com um responsável designado.
