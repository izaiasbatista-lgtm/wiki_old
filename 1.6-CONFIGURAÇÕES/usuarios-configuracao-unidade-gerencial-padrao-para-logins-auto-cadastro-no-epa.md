# Usuários – Configuração Unidade gerencial padrão para logins Auto – Cadastro no EPA
> **Um novo parâmetro foi criado no EPA para que os novos logins criados a partir do auto cadastro no EPA recebam automaticamente uma unidade gerencial padrão no EPA.** 

**1 –** Acesse a página de parâmetros do Sistema:

_**Configuração > Parametrização do Sistema**_

**2 –** No menu selecione: **Usuários** e no campo de pesquisa digite: **Unidade gerencial.**

O parâmetro se chama: 

<table id="tableParametros" class="dataTable table table-bordered table-condensed wp_100 no-footer" style="width: 94.1718%;" role="grid" bgcolor="" aria-describedby="tableParametros_info"><tbody><tr class="odd" role="row"><td style="text-align: center; width: 100%;"><em>Informe o código da unidade gerencial padrão do usuário para auto-cadastro.</em></td></tr></tbody></table>

Veja:

![](https://wiki.simeon.com.br/wp-content/uploads/2021/04/img_60870e1e5f75e.png)

**3 –** No campo Valor, **insira o número do código da Unidade Gerencial padrão** que os usuários do Auto Cadastro receberão no EPA.

![](https://wiki.simeon.com.br/wp-content/uploads/2021/04/img_60870e63f029c.png)

![](https://wiki.simeon.com.br/wp-content/uploads/2020/06/img_5eecbdba05736.png)

_Acessando a página de configuração das Unidades Gerenciais no EPA, você conseguirá ver o código das unidades!_

_Assim você poderá verificar qual código você precisa, para configuração deste parâmetro._

_Acesse a página de cadastro das unidades gerenciais no EPA**: Configuração > Unidades Gerenciais.**_

**4 –** A partir desta configuração no parâmetro informado, todos os usuários criados a partir do auto cadastro no EPA terão a unidade gerencial padrão selecionada em suas permissões de unidades.

Exemplo:

![](https://wiki.simeon.com.br/wp-content/uploads/2021/04/img_60871189a1705.png)
