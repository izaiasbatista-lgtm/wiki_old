# Parametrização – Usuários: Exclusão de informações dos usuários inativos
![](https://wiki.simeon.com.br/wp-content/uploads/2021/07/img_60f9af23432dd-e1631299903164-213x300.png)

**Nessa versão incluímos um novo parâmetro no EPA para configurar a quantidade de dias em que o sistema deverá manter as informações pessoais dos usuários que já estão inativos.**

**Essa alteração vai ao encontro a Lei Geral de Proteção de Dados (LGPD), onde não se pode conservar dados pessoais por longos períodos.**

**Assim, o novo parâmetro estará disponível no sistema e você poderá ativá-lo ou não.** 

**O parâmetro quando ativo e configurado, faz com que após um determinado período, usuários que estão inativos no EPA tenham suas informações pessoais apagadas. Os nomes dos usuários inativos também são alterados, para o cargo registrado ou apenas para a sinalização: “usuário inativo”.**

Veja como aplicar essa melhoria:

**1 –** Para utilizar a melhoria, acesse os parâmetros do sistema pelo caminho:

**1.1.** Acesse: **Configuração> Parametrização do Sistema,**

**1.2.** Selecione o **MENU: Usuários,**

**1.3.** No parâmetro**: Informe a quantidade de dias que as informações pessoais dos usuários serão mantidas no sistema após a inativação dele. (Encontro a Lei Geral de Proteção de Dados, onde não posso conservar dados pessoais por longos períodos).**

Insira a quantidade de dias desejada para que o EPA conserve as informações pessoais de usuários inativos.

![](https://wiki.simeon.com.br/wp-content/uploads/2021/10/img_615b57a5d3201.png)

**2 –** Após o período informado no parâmetro, o EPA valida a quantidade de dias em que os usuários já estão inativos no sistema **e remove as informações pessoais que foram cadastradas destes** **usuários.**

O nome destes serão substituídos pelo cargo. Caso esses usuários não tenham cargo cadastrado em seus registros, os nomes serão substituído por **“usuário inativo”.**

Veja como ficará a listagem com os usuários inativos no EPA!

Acesse em: **Configuração> usuários> gerenciar usuários,** siga as instruções:

**2.1.** No filtro **Status** da página _Gerenciar Usuário_, selecione: **Usuários inativos,** e pesquise para o sistema listar esta informação.

**2.2.** Os usuários que tiveram as alterações realizadas devido ao parâmetro, já estarão com os nomes de cada cargo ou sinalizados com o termo usuário inativo. Veja:

![](https://wiki.simeon.com.br/wp-content/uploads/2021/10/img_615b55c9a995a.png)

**3 –** Caso não queira ativar o parâmetro e essa funcionalidade para apagar todos os dados dos usuário inativos, é só deixar o valor de configuração no parâmetro como: “zero”. Veja:

![](https://wiki.simeon.com.br/wp-content/uploads/2021/10/img_615b5806d8a68.png)

![](https://wiki.simeon.com.br/wp-content/uploads/2021/07/istockphoto-921459570-612x612-1-e1626985188707-167x300.jpg)
