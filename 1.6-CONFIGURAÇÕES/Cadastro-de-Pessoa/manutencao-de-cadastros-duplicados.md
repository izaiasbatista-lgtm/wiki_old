# Manutenção de Cadastros Duplicados
O EPA oferece a opção de eliminar cadastros de usuários duplicados preservando a integridade do histórico de atividades realizadas.

Para realizar a manutenção acesse o menu  ![](https://wiki.simeon.com.br/wp-content/uploads/2020/04/img_5e84e92d05c7c.png) /PORTAL /Cadastro de Pessoas/ Manutenção Duplicados

![](https://wiki.simeon.com.br/wp-content/uploads/2020/04/img_5e84ebd606133.png)

Use o filtro (1) para indicar  os campos para a identificação da similaridade e clique no botão PESQUISAR.

Na lista  (2) selecione os nomes que são similares e clique no botão PRÓXIMO.

![](https://wiki.simeon.com.br/wp-content/uploads/2020/04/img_5e84ed0c2c4e6.png)

Na próxima tela (3) serão listados os nomes selecionados e a sinalização de qual está com o cadastro de usuário ativo.

Selecione o nome que deve ficar no EPA, caso algum nome tenha usuário ativo, dê preferência a ele, na seleção para continuar no EPA. 

Clique no botão ATUALIZAR .

![](https://wiki.simeon.com.br/wp-content/uploads/2020/04/img_5e84ee7122756.png)

Após a tela ser atualizada a listagem ficará vazia.

Clique no botão VOLTAR.

Todas as atividades que estiverem relacionadas ao nome **não selecionado** serão herdadas pelo nome selecionado.
