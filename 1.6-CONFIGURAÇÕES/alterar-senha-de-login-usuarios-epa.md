# Alterar Senha de login usuários EPA
**Alterar Senha de login usuários EPA**

O EPA conta com uma periodicidade em dias que você poderá configurar para que os usuários do sistema alterem sua senha de login.

-   Em parametrização de sistema:

![](https://wiki.simeon.com.br/wp-content/uploads/2020/04/img_5e9db68c63f7e.png)

Caminho para parametrização do sistema

Filtrando em Menu: _usuários,_

para facilitar a busca digitando no campo pesquisar: _senha._

![](https://wiki.simeon.com.br/wp-content/uploads/2020/04/img_5e9db7448ed85.png)

Filtro para encontrar a parametrização.

Você encontrará a parametrização:

<table id="tableParametros" class="dataTable table table-bordered table-condensed wp_100 no-footer" style="width: 744px;" role="grid" bgcolor="" aria-describedby="tableParametros_info"><tbody><tr class="odd" role="row"><td style="text-align: center; width: 734.8px;"><em><strong>Informe a periodicidade em dias que o usuário deverá alterar a senha</strong></em></td></tr></tbody></table>

![](https://wiki.simeon.com.br/wp-content/uploads/2020/04/img_5e9db89cb20ee.png)

Parametrização.

E no campo valor você pode inserir quantos dias deseja que o sistema dispare uma ação para os usuários alterarem suas senhas de acesso ao EPA.

Para alterar a senha o seguinte ação será disparada:

![](https://wiki.simeon.com.br/wp-content/uploads/2020/04/img_5e9db8746ba11.png)

Tela de alteração se senha EPA.

Qualquer dúvida, entre em contato!
