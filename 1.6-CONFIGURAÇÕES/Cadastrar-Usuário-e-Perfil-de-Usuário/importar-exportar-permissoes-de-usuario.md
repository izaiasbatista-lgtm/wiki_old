# Importar/Exportar permissões de usuário
Essa funcionalidade permite que importe e exporte as permissões de um usuário para outro.

-   Para importar acesse o cadastro do usuário e clique no ícone  ![](https://wiki.simeon.com.br/wp-content/uploads/2020/07/img_5f04e31e34f54.png), na importação serão copiadas as permissões de outro  usuário para esse usuário que esta no cadastro. Selecione o **usuário de origem(1),** que será quem vai transferir suas permissões para o usuário do cadastro e clique em **Importar**;

![](https://wiki.simeon.com.br/wp-content/uploads/2020/07/img_5f04e3df9e3ef.png)

Para exportar clique no ícone ![](https://wiki.simeon.com.br/wp-content/uploads/2020/07/img_5f04e35d08d8b.png),  na exportação serão copiadas as permissões do usuário do cadastro para outro usuário. Selecione o **usuário de destino(2),** que será quem vai receber as permissões e clique em **Exportar.**

![](https://wiki.simeon.com.br/wp-content/uploads/2020/07/img_5f04e4bf438c0.png)
