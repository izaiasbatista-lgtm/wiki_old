# Criar grupo de usuários
No EPA existe a possibilidade de criar grupos de usuários independente da unidade gerencial que pertencem ou perfil de permissões.

Para criar o grupo siga os passos abaixo.

-   Acesse o menu **Portal → Comunicação → Cadastrar grupo de usuários.**
    

![](https://wiki.simeon.com.br/wp-content/uploads/2020/02/img_5e4542d0c36c4.png)

-   Informe o nome do grupo no campo **Nome do grupo** e clique no botão **Salvar.**

![](https://wiki.simeon.com.br/wp-content/uploads/2020/02/img_5e4543866a08d.png)

# **OBSERVAÇÃO**:

![](https://wiki.simeon.com.br/wp-content/uploads/2022/06/img_62a0ad6cb970e-300x284.png)

_Apenas os usuários:_

-   -   -   -   _Usuário Inclusão e,_
            -   _Super Usuários, possuem permissão para poder **Editar** ou **Excluir** Grupos de Usuários cadastrados._

-   Clique no botão **Selecionar Usuários**  e selecione os usuários que farão parte do grupo  **(1)**.

-   Na seção **Compartilhar com:** clique no botão **Selecionar Usuários** e selecione os usuários que verão o grupo na tela de seleção de usuário **(2)**.

Os nomes dos usuários selecionados nas seções **Usuários** e **Compartilhar com:** serão listados na tela e estarão inseridas no grupo.

O grupo será listado na tela de pesquisa de usuário como sinalizado abaixo. Ao selecionar o grupo os nomes dos usuários contidos no grupo, _no momento_, serão listados na seção **Usuários Selecionados**.

![](https://wiki.simeon.com.br/wp-content/uploads/2020/02/img_5e454c0b88b34.png)
