# Usuário – Bloquear Acesso Externo
**1.** Para configurar o bloqueio de acesso externo para usuários específicos no EPA, siga estes passos:

**⇒ Caso deseje fazer a configuração por Usuário:** Acesse **Parametrização → Gerenciar Usuários**, acesse o cadastro do usuário que deseja configurar.  

![](https://wiki.simeon.com.br/wp-content/uploads/2024/01/img_6598499b5846f.png)

**⇒ Caso deseje fazer a configuração por Perfil:** Ou acesse **Parametrização → Perfil de Usuários**, acesse o cadastro do perfil que deseja configurar.  

![](https://wiki.simeon.com.br/wp-content/uploads/2024/01/img_659849ba9fcf2.png)

**2.** Na aba Permissões acesse o menu **Parametrização →  Usuários** e marque a permissão **Bloquear Acesso Externo.**

![](https://wiki.simeon.com.br/wp-content/uploads/2024/01/img_659849f4ecab6.png)

**3.** No menu do EPA clique na ![](https://wiki.simeon.com.br/wp-content/uploads/2024/01/img_659847f4c5add.png)→ **Parametrização do Sistema**, no campo **IP Interno Servidor** informe o IP interno que o acesso será liberado para o usuário.  
Separe os IP’s com vírgula caso seja incluído 2 ou mais.

O IP que será informado é o IP Fixo da empresa, do firewall.

![](https://wiki.simeon.com.br/wp-content/uploads/2024/01/img_659848213e19e.png)
