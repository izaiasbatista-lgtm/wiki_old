# Planejamento – Melhoria na apresentação dos dados no relatório de indicadores não alimentados e a configuração das unidades estratégicas de negócio no EPA
**Principais Alterações:**

-   Agora é possível configurar unidades gerenciais no EPA para serem **Unidades Estratégicas de Negócio**, assim você poderá gerenciar melhor os indicadores das unidades gerenciais que você tem acesso, quanto a alimentação destes para alcançar suas metas estipuladas.

-   Os gráficos apresentando o percentual de alimentação dos indicadores das unidades estratégicas de negocio estão no relatório de indicadores não alimentados. Planejamento > relatórios> indicadores não alimentados.

-   A configuração de uma unidade gerencial no EPA para ser uma Unidades Estratégicas de Negócio está no ambiente de cadastro e edição das unidades gerenciais no sistema. Configuração> Unidades Gerenciais.
