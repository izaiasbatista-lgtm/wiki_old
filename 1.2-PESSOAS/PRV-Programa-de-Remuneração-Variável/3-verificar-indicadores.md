# 2- Verificar Indicadores
**![](https://wiki.simeon.com.br/wp-content/uploads/2023/05/depositphotos_38689733-stock-photo-giraffe.webp)**

**Realize a Análise nos Indicadores que Farão Parte do Programa.**

 -> Agora é a hora de determinar quais indicadores farão parte do programa. É o momento de focar nos objetivos e resultados desejados, identificando quais indicadores são relevantes para alcançá-los.

-   Para acessar esses indicadores, siga o caminho: Planejamento > Painel de Indicadores > Selecione a unidade gerencial e a etapa desejada.

Exemplo:

![](https://wiki.simeon.com.br/wp-content/uploads/2023/11/img_6548e3968d59e.png)

Com todas as regras do programa alinhadas com a empresa, participantes definidos e indicadores selecionados, estamos prontos para avançar para o próximo passo: o cadastro do programa no sistema.
