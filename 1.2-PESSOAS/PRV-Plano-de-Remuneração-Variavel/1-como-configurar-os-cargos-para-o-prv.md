# 1- Como Configurar os Cargos dos Participantes do PRV
**![](https://wiki.simeon.com.br/wp-content/uploads/2023/05/depositphotos_38689733-stock-photo-giraffe.webp)**

Como configurar os cargos dos colaboradores no EPA. 

**Passo 1.**   Para acessar a essa tela **Configuração → Portal  → Cadastro de Pessoas → Cargos.** 

Exemplo:

**1 –** Primeiramente, você precisa liberar a permissão em seu usuário para ter acesso à configuração no ambiente Cargos. Para fazer a configuração acesse o caminho: **Configuração → Usuários →   Gerenciar Usuários → Usuário que terá Acesso → Parametrização → Portal → Cadastro de Pessoas → Selecionar a opção Cargos.** 

Assim, terá acesso a essa tela onde irá realizar o cadastro dos cargos dos colaboradores no sistema onde esse cargo se refletirá no cadastro do funcionário. 

          **2-** Informe o nome do novo cargo e na sequência clique em salvar . 

Exemplo:

![](https://cdn.discordapp.com/attachments/1123353310661967998/1170910432068903032/image.png?ex=655ac251&is=65484d51&hm=fb91e0c80195705430b06c40240cd01f3babd2cccb7243a47fec583b811ae8c7&)

 **2-  Como realizar o vinculo dos cargos aos participantes;**      

Na sequência, será necessário realizar o vínculo do cargo cadastrado ao participante do programa. Assim, quando você cadastrar um cargo, ele será automaticamente exibido no cadastro da pessoa. 

O caminho para acessar é Menu> Clique na 1- Lupa e digite o nome da pessoa > clique em editar > Ações > Editar para acessar a tela de cadastro do colaborador. 

Exemplo:

![](https://wiki.simeon.com.br/wp-content/uploads/2023/11/img_6548d8347c39e.png)

![](https://wiki.simeon.com.br/wp-content/uploads/2023/11/img_6548d869a685b.png)

Exemplo:

![](https://wiki.simeon.com.br/wp-content/uploads/2023/11/img_6548d54d31254.png)

Lembre-se de que o perfil da pessoa se destina a funcionários, então todos os cargos que você cadastrar aqui aparecerão em uma lista na tela, e você deverá selecionar a qual cargo pertence.

A definição do cargo é fundamental para determinar quais regras se aplicam ao funcionário no programa.
