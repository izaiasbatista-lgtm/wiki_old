# Como Criar e Vincular Cargos aos Cadastros de Pessoas
**![](https://wiki.simeon.com.br/wp-content/uploads/2023/05/depositphotos_38689733-stock-photo-giraffe.webp)**

Este artigo irá te auxiliar mostrando o passo a passo de como criar um cargo e vincular aos cadastros de pessoas

**Passo 1.**   Para acessar a essa tela **Configuração → Portal  → Cadastro de Pessoas → Cargos.** 

Exemplo:

**1 –** Primeiramente, você precisa liberar a permissão em seu usuário para ter acesso à configuração no ambiente Cargos. Para fazer a configuração acesse o caminho: **Configuração → Usuários →   Gerenciar Usuários → Usuário que terá Acesso → Parametrização → Portal → Cadastro de Pessoas → Selecionar a opção Cargos.** 

Assim, terá acesso a essa tela onde irá realizar o cadastro dos cargos dos colaboradores no sistema onde esse cargo se refletirá no cadastro de funcionário. 

         **2 –** Para acessar essa configuração de Cargos, vamos seguir o caminho**: Parametrização → Portal → Cadastro de Pessoas**

Nessa tela vamos ter acesso para incluir um cargo novo, alterar ou até mesmo excluir um já existente.

![](https://wiki.simeon.com.br/wp-content/uploads/2023/11/img_6548f64f2dee7.png)

**Passo 2.** Ao entrar no **Cadastro de Pessoa**, conseguiremos incluir qualquer um desses cargos já criado:
