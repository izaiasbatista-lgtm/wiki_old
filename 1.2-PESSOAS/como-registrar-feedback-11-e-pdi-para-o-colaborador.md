# Como registrar Feedback 1:1 e PDI para o colaborador
**![](https://wiki.simeon.com.br/wp-content/uploads/2023/05/depositphotos_38689733-stock-photo-giraffe.webp)**

O cadastro do colaborador permite que os gestores acompanhem e desenvolvam suas equipes. Nele, é possível registrar Feedbacks 1:1, incluir Planos de Desenvolvimento Individual (PDI) sem a necessidade de vínculo com uma avaliação de desempenho e consultar o histórico de avaliações do colaborador.

Neste artigo, explicamos como acessar essa funcionalidade, suas principais características e as permissões necessárias para utilizá-la.

**Atenção: Essa funcionalidade esta disponível apenas para clientes que possuem o modulo de Pessoas.**

**1-** Para acessar a tela de análise de pessoas, clique no ícone da **Lupa** e pesquise pelo colaborador desejado. Clique no botão **Ações** e selecione a opção **Feedback 1:1**.

![](https://wiki.simeon.com.br/wp-content/uploads/2025/02/img_67a50f1bbce07.png)

**2-** Na aba **Análise de Pessoas**, o gestor pode:

Incluir **Feedbacks 1:1** para o colaborador;

![](https://wiki.simeon.com.br/wp-content/uploads/2025/01/Sem-titulo3.png)

Cadastrar um **PDI (Plano de Desenvolvimento Individual)** sem vínculo com uma avaliação de desempenho;

![](https://wiki.simeon.com.br/wp-content/uploads/2025/01/Sem-titulo2.png)

Visualizar o **histórico de avaliações** do colaborador.

![](https://wiki.simeon.com.br/wp-content/uploads/2025/01/Sem-titulo.png)

**Observação:** A aba **Análise de Pessoas** está disponível apenas para cadastros com o **Tipo Pessoa: Funcionário.**

### **Permissões Necessárias:**

Para utilizar essas funcionalidades, o usuário precisa das seguintes permissões:  
✅ **Gestão das Avaliações**  
✅ **Planos de Desenvolvimento**  
✅ **Ser Gestor de Unidade**  
✅ **Permitir Acessar e Alterar a Ficha de Funcionários**.
