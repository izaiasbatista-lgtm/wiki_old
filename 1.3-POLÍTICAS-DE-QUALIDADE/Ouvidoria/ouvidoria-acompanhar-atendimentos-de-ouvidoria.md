# Ouvidoria- Acompanhar Atendimentos de Ouvidoria
**![](https://wiki.simeon.com.br/wp-content/uploads/2023/05/depositphotos_38689733-stock-photo-giraffe.webp)**

**Neste artigo, você aprenderá, passo a passo, como gerar o link para o acompanhamento de um atendimento de ouvidoria. Além disso, vamos apresentar a nova atualização do EPA, que agora omite o nome do colaborador responsável pela inclusão ou alteração de um acompanhamento quando o link é compartilhado externamente com o cliente ou paciente.**

Primeiramente, para filtrar um chamado por meio de um link específico, é necessário ter em mãos o número do protocolo, disponível no registro do atendimento realizado pela ouvidoria.

**Exemplo:**

![](https://wiki.simeon.com.br/wp-content/uploads/2023/11/img_6548fe48c3989.png)

Tendo o número de protocolo, vamos no cadastro de usuário: **Parametrização → Usuários → Gerenciar Usuário → Selecionar o Usuário que está desejando para gerar o link → Integrações**

![](https://wiki.simeon.com.br/wp-content/uploads/2025/03/img_67df05c96625c.png)

**![](https://wiki.simeon.com.br/wp-content/uploads/2025/03/img_67df06826e9d8.png)**

Ao clicar no botão Gerar link para acompanhar atendimentos de ouvidoria, o EPA vai gerar o link para a consulta do protocolo e Informe, no  campo da tela  o número do protocolo correspondente.

**Veja:**

![](https://wiki.simeon.com.br/wp-content/uploads/2023/11/img_65492ee5c5180.png)

Para garantir que os acompanhamentos apareçam no link de consulta, é necessário marcar a opção **“Mostrar no Link externo de ouvidoria”**. Isso permite que os detalhes dos acompanhamentos sejam visíveis no link acessado externamente.

![](https://wiki.simeon.com.br/wp-content/uploads/2025/03/img_67df097ce77e8.png)

Ao acessar o resultado do protocolo teremos as seguintes informações disponíveis:

![](https://wiki.simeon.com.br/wp-content/uploads/2025/03/img_67df0af0a9f04.png)

-   **Número do registro de atendimento**: Identificação única do atendimento registrado no sistema, utilizado para rastrear e referenciar o caso específico.
    
-   **Protocolo ANS**: Número de protocolo associado ao atendimento, que pode ser utilizado para rastrear o caso junto à ANS.
    
-   **Status**: Indica a situação atual do atendimento, como “Em andamento”, “Concluído”, “Pendente”, entre outros.
    
-   **Demandante**: A pessoa ou entidade que fez a solicitação ou apresentou a demanda.
    
-   **Demanda**: Descrição do problema, solicitação ou questão que está sendo tratada no atendimento.
    
-   **Data fim prevista**: Data estimada para a conclusão do atendimento ou resolução da demanda.
    
-   **Descreva o atendimento**: Detalhes sobre as ações tomadas, andamento do processo ou outras informações relevantes relacionadas ao atendimento.
    

![](https://wiki.simeon.com.br/wp-content/uploads/2025/03/img_67df0bd6032b7.png)

A alteração feita garante que o nome do colaborador responsável pela inclusão ou alteração de um acompanhamento não será exibido para o cliente no link externo enviado pela ouvidoria. No entanto, o sistema continuará registrando o nome do colaborador internamente, para uso exclusivo da empresa. Essa mudança afeta apenas a visualização externa, sem impactar as visualizações internas do acompanhamento.

![](https://wiki.simeon.com.br/wp-content/uploads/2025/02/img_67bc6510c3a37.png)
