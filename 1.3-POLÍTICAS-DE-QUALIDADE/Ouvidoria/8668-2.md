# Parametrização – Ouvidoria: Código padrão ANS para registros de atendimento externo
![](https://wiki.simeon.com.br/wp-content/uploads/2021/07/img_60f9af23432dd-e1631299903164-213x300.png)

**Nessa versão incluímos um novo parâmetro no EPA para configurar o código padrão ANS a ser utilizado nos registros de atendimentos gerados pelo formulário externo no EPA.**

**Através do parâmetro, se configurado código ANS, após salvar o registro de atendimento de ouvidoria externo, o sistema apresentará o código do atendimento no seguinte padrão:**

_CÓDIGO DE REGISTRO NA ANS + ANO + MÊS + DIA e código do registro de atendimento no EPA._

![](https://wiki.simeon.com.br/wp-content/uploads/2021/10/img_61604f1bee4bf.png)

1\. Código ANS, 2. Data atual, 3. Código do registro de atendimento no EPA

Veja como utilizar essa melhoria:

**1 –** Para utilizar a melhoria, acesse os parâmetros do sistema pelo caminho:

**1.1.** Acesse: **Configuração> Parametrização do Sistema,**

**1.2.** Selecione o **MENU: Ouvidoria,**

**1.3.** No parâmetro**: Informe o código ANS que será usado no registro de atendimento externo da ouvidoria:**

Insira o código ANS, que deseja utilizar como padrão, após criar um registro externo de ouvidoria.

![](https://wiki.simeon.com.br/wp-content/uploads/2021/10/img_6160532ea657f.png)

![](https://wiki.simeon.com.br/wp-content/uploads/2021/10/img_616055a4adf29.png)

**2 –** Após configurar o código ANS no parâmetro indicado, sempre que houver um registro de ouvidoria externo, o sistema apresentará ao usuário o **protocolo do atendimento,** com o seguinte padrão: _CÓDIGO DE REGISTRO NA ANS + ANO + MÊS + DIA e código do registro de atendimento no EPA._

Veja como será apresentado esta informação após salvar um registro de ouvidoria externo:

![](https://wiki.simeon.com.br/wp-content/uploads/2021/10/img_6160570cdc6bd.png)

![](https://wiki.simeon.com.br/wp-content/uploads/2021/09/img_613f69451330c.png)

**3 –** Caso não queira ativar o parâmetro e essa funcionalidade para apresentar um código padrão após salvar  registros de ouvidoria externo, é só deixar o valor de configuração no parâmetro como: “zero”. Veja:
