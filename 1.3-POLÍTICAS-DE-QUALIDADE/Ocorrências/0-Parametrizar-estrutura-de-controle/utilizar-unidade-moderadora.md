# Ocorrências – Utilizar Unidade Moderadora
**![](https://wiki.simeon.com.br/wp-content/uploads/2023/05/depositphotos_38689733-stock-photo-giraffe.webp)**

**Nesse artigo, vamos falar sobre a funcionalidade de Unidade Moderadora no cadastro e na visualização de ocorrências.** **A Unidade Moderadora é utilizada para organizar e restringir o acesso às ocorrências, especialmente em ambientes onde existem múltiplos departamentos da Qualidade, como Ouvidoria e setores responsáveis por Não Conformidades. Antes de habilitar essa funcionalidade, é necessário configurar um parâmetro específico no sistema, permitindo que o campo de seleção da Unidade Moderadora apareça no momento do cadastro da ocorrência.**

#### **Parametrização Inicial**

Antes de realizar o cadastro da Unidade Moderadora, é necessário ativar um parâmetro no sistema. Para isso:

1.  Clique em Parametrização.
    
2.  Acesse a opção **Parametrização de Sistema**.
    
3.  Pesquise pelo parâmetro:  
      
    **“Ao incluir uma ocorrência o usuário poderá escolher uma unidade moderadora.”**
    
4.  Marque esse parâmetro como **Sim**.
    

**Veja:**

![](https://wiki.simeon.com.br/wp-content/uploads/2025/05/img_6833b34426b16.png)

Essa configuração permite que o campo de Unidade Moderadora seja exibido no momento do cadastro da ocorrência.

#### **Cadastro da Unidade Moderadora**

Após a parametrização, siga os passos abaixo para configurar uma Unidade Moderadora:

1.  Acesse o cadastro de **Unidades Gerenciais,** seguindo o caminho **Parametrização → Unidades Gerenciais**.
    
2.  Crie ou Selecione a unidade que será definida como moderadora.
    
3.  Marque a opção  **Moderadora Ocorrência**.
    

**Importante:** Apenas unidades com essa opção marcada serão exibidas no campo de seleção da ocorrência.

![](https://wiki.simeon.com.br/wp-content/uploads/2025/05/img_6833b3fe90222.png)

#### **Inclusão da Ocorrência**

Após realizar a parametrização e configurar a Unidade Moderadora, o campo **Unidade Moderadora** estará disponível **ao criar uma nova ocorrência**.  
  
Esse campo aparecerá no formulário de cadastro da ocorrência, permitindo que o usuário selecione a unidade responsável pela moderação.

As unidades listadas nesse campo serão exibidas em **ordem crescente**, conforme o **código** cadastrado das unidades gerenciais.

**Veja:**

![](https://wiki.simeon.com.br/wp-content/uploads/2025/05/img_6833b7e82f41c.png)

#### **Pesquisa por Unidade Moderadora**

Caso deseje consultar ocorrências específicas de uma Unidade Moderadora:

1.  Acesse a tela de **filtros de pesquisa** de ocorrência.
    
2.  Utilize o filtro **Unidade Moderadora**  para refinar os resultados.
