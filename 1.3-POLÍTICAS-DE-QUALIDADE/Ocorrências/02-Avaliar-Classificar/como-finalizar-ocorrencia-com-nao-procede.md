# Ocorrências – Como finalizar ocorrência como Não procede
**![](https://wiki.simeon.com.br/wp-content/uploads/2023/05/depositphotos_38689733-stock-photo-giraffe.webp)**

**Nesse artigo, vamos mostrar como finalizar uma ocorrência classificada como “Não Procede” no EPA. O encerramento deve ser feito na fase _Avaliar Ocorrência_ pelo Analista da Qualidade, seguindo um breve passo a passo. Também explicamos quando o botão _Marcar como Não Procede_ estará disponível.**

Quando a ocorrência for classificada como _Não Procede_, ela deve ser finalizada na fase **Avaliar Ocorrência**, pelo Analista da Qualidade.  
  
Para isso, acesse o cadastro da ocorrência, clique na aba **Encerrar a Ocorrência** (1), altere o **Status** para _Concluído_ (2), preencha o campo **Comentário para Conclusão da Ocorrência** (3) e clique no botão **Marcar como Não Procede**.

![](https://wiki.simeon.com.br/wp-content/uploads/2021/03/img_6052780422967.png)

**Observação:** Se o **Tipo de Ocorrência** já estiver definido como _Não Procede_, o botão **Marcar como Não Procede** **não será exibido**. Para que o botão apareça, é necessário que a ocorrência esteja inicialmente com outro tipo selecionado.

Ao clicar em **Marcar como Não Procede**, a ocorrência será concluída e o sistema irá atualizar automaticamente o tipo para _Não Procede_.
