# Riscos -Como inativar uma unidade gerencial cadastrada para analise do Risco.
![](https://wiki.simeon.com.br/wp-content/uploads/2021/06/giraffe-e1623062804726-169x300.png)

**Ca****so não seja mais necessário a realização de análise de risco a partir de uma unidade gerencial específica, você poderá inativar a unidade gerencial  vinculada neste risco.**

-   -   -   -   -   -   **Ao inativar uma unidade, o EPA retira as análises pendentes e futuras de seus responsáveis desta unidade;**
                    -   **O risco relacionado a esta unidade gerencial que foi inativa passa a não aparecer mais na** **matriz de risco no sistema.**

Veja como inativar a unidade vinculada ao risco:

**1 –** Acesse um de seus riscos no EPA, pelo caminho: 

> _Politica de qualidade>Riscos> Gestão de Risco> **Edite** um Risco que deseja **inativar** uma unidade gerencial vinculada para realizar análises_

-   -   -   Acessando um risco, no ambiente para vincular as unidades gerenciais, você verá o checkbox ativo, nas unidades listadas para fazer análise.

![](https://wiki.simeon.com.br/wp-content/uploads/2021/06/img_60be72716a473.png)

**2 –** Clique no checkbox para inativar uma unidade gerencial vinculada, que não precisa mais estar no risco para realização de  análises:

![](https://wiki.simeon.com.br/wp-content/uploads/2021/06/img_60be740c50f9e.png)

**3 –** Ao inativar uma unidade gerencial vinculada no risco, o EPA irá retirar:

-   -   -   -   O registro da última análise feita por essa unidade (inativa) da matriz de riscos;
            -   Não será possível pesquisar esse risco através dos filtros de unidade gerencial (unidade inativa);
            -   Também não será contabilizado os dados relacionados a unidade gerencial inativa deste Risco no DASHBOARD;
            -   As análises pendentes e as futuras correspondentes à unidade gerencial vinculada que foi inativa, não serão apresentadas aos seus responsáveis pelo box (caixinha) de acesso na página inicial do EPA.
            -   No respectivo Risco o  EPA passará a pesquisar somente as barreiras e causas das unidades **ativas** para fazer as  análises.

![](https://wiki.simeon.com.br/wp-content/uploads/2021/06/giraffe-e1623062804726-169x300.png)

**Quem pode selecionar/marcar o check ativo ou inativo de uma unidade gerencial vinculada no risco?**

Somente:

-   -   -   -   -   -   -    _Super usuário,_ 
                        -   _Analista de risco e_ 
                        -   _O Responsável do risco_

> **Caso precise ativar novamente a unidade gerencial para futuras análises no risco, é só selecioná-la como ativa novamente! o EPA ativará as análises desta unidade gerencial no risco.**
