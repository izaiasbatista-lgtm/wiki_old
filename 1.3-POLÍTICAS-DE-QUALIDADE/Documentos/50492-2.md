# Ouvidoria – Nova Parametrização de Campo Chave no Formulário Externo
**![](https://wiki.simeon.com.br/wp-content/uploads/2023/05/depositphotos_38689733-stock-photo-giraffe.webp)**

**Neste artigo vamos explicar sobre a criação de uma nova forma de parametrização no sistema EPA, que permitirá escolher o campo chave obrigatório no formulário externo da Ouvidoria. A ideia é oferecer maior flexibilidade e padronização nas informações coletadas, além de evitar inconsistências.**

A nova parametrização permite escolher entre três opções para o **campo chave obrigatório** no formulário externo da Ouvidoria. O campo chave será exibido como o primeiro item no formulário e terá um asterisco vermelho (\*) para indicar que é obrigatório.

As opções disponíveis para o campo chave são:

-   **Matrícula/Número do Cartão**
    
-   **E-mail**
    
-   **CNPJ/CPF**
    

Para configurar a opção desejada, acesse: **Parametrização → Parametrização do Sistema**. Dentro dessa tela, você poderá escolher o campo chave obrigatório que será exibido no formulário externo da Ouvidoria.

**Veja:**

![](https://wiki.simeon.com.br/wp-content/uploads/2025/05/img_6817c8ffc44e1.png)

**Ao clicar no “Valor” → você verá as opções: Matrícula/Número do Cartão, E-mail e CNPJ/CPF:**

![](https://wiki.simeon.com.br/wp-content/uploads/2025/05/img_6817c929a9982.png)

Sendo CNPJ/CPF o campo chave que será utilizado no formulário externo de Ouvidoria, seguindo o caminho: **Parametrização → Usuários → Gerenciar Usuário → Configurar Permissões → Integrações → Gerar link para registro de atendimentos da ouvidoria**, você verá em destaque o campo chave selecionado.
