# Documentos- Cópias Controladas e Não Controladas
**![](https://wiki.simeon.com.br/wp-content/uploads/2023/05/depositphotos_38689733-stock-photo-giraffe.webp)**

**Neste artigo, abordaremos o processo de geração das cópias controladas e não controladas. Explicaremos as diferenças entre esses dois tipos de documentos, suas finalidades e a importância de cada um no contexto de gestão da informação. Também vamos detalhar as etapas envolvidas na emissão dessas cópias, desde a solicitação até o registro e distribuição, destacando os cuidados necessários para garantir a rastreabilidade e o cumprimento dos requisitos normativos.**

 Para solicitar a geração de cópias ao criar um documento, certifique-se de que a opção **“Controlar Cópias?”** esteja ativada nas informações básicas, conforme mostrado na imagem abaixo:

![](https://wiki.simeon.com.br/wp-content/uploads/2025/02/img_67bf16d41e582.png)

Quando os documentos forem publicados, acesse a tela de cadastro do documento, clique no menu lateral Cópias impressas e clique no botão  Cópias impressas.

![](https://wiki.simeon.com.br/wp-content/uploads/2025/02/img_67bf204a39c3b.png)

Na tela de “Controle de Cópias Impressas” informe se vai ser “Cópias Controladas” (1), em seguida informe a data de vencimento do documento (2), quem recebeu o documento (3), a quantidade de cópias entregues (4), uma observação (5) e clique no botão Salvar (6).

![](https://wiki.simeon.com.br/wp-content/uploads/2025/02/img_67bf292f4010b.png)

Quando clicar em salvar será habilitado o botão para gerar o PDF (7) do documento com o código gerado da cópia, e o campo para informar a data de recolhimento da cópia (8).

![](https://wiki.simeon.com.br/wp-content/uploads/2025/02/img_67bf2a08718cc.png)

Para gerar uma Cópia não controlada é só selecionar a opção “Copias não controladas”, a diferença é que a tela de controle de cópias não vai ter algumas opções como mostrado abaixo:

![](https://wiki.simeon.com.br/wp-content/uploads/2025/03/img_67da33d51d37b.png)

Em Cópias Impressas podemos ver que conseguimos acompanhar quais cópias são controladas e não controladas:

![](https://wiki.simeon.com.br/wp-content/uploads/2025/03/img_67da348409d97.png)

    Existem permissões de controle para a geração de cópias controlada (Gerar Cópia Controlada):

![](https://wiki.simeon.com.br/wp-content/uploads/2023/10/img_652ea52454251.png)

-   Para imprimir uma cópias controlada o usuário no EPA necessita ter ao menos umas das permissões a seguir:

-   -   **Permissões de usuário:**
        -   Analista de Documentos da UEN do documento,
        -   Super Usuário;

-   -   **Permissão do Documento:** 
        -   Usuários inseridos no documento que possuem a configuração de acesso em: **Políticas de Qualidade → Documentos → Gestão de Documentos → (Editar um Documento) → Aba “Permissões” → Checkbox flegado em: “Imprimir Documento”**.
            
        -   Observação: A permissão de imprimir é para o botão de gerar uma cópia controlada no sistema.
            

![](https://wiki.simeon.com.br/wp-content/uploads/2022/12/img_63ac92d298c94.png)

    Para definir o texto que será exibido nas cópias não controladas ao imprimir um documento, siga os passos abaixo:

Acesse o menu e siga o caminho:  
  
**Parametrização → Parametrização do Sistema**

 ![](https://wiki.simeon.com.br/wp-content/uploads/2025/02/img_67bf31ecb8e54.png)

1.  No campo de pesquisa, digite **“Cópias”**.
    
2.  Localize a opção **“Definir o texto padrão para ser exibido no arquivo PDF das cópias não controladas”**.
    
3.  Insira o texto desejado e salve as alterações.
    
    ![](https://wiki.simeon.com.br/wp-content/uploads/2025/02/img_67bf32bdb853c.png)
    
4.  A Data de Validade da cópia é calculada automaticamente com base nos dias configurados no parâmetro **Quantidade de dias para vencimento as cópias impressas.**

**Observação:** Se a quantidade de dias informada nesse parâmetro **for maior do que a Data de Validade do Documento**, a **Data de Validade da cópia impressa** será definida como **igual à Data de Validade do documento.**
