# Ouvidoria – Novos Campos – melhorias na versão 161
![](https://wiki.simeon.com.br/wp-content/uploads/2022/06/Imagens-Engracado-PNG-e-Vetor_-com-Fundo-Transparente-Para-Download-Gratis-_-Pngtree-removebg-preview-164x300.png)

**Nesta Versão o módulo de Registro de Ouvidoria ganhou algumas opções adicionais no formulário, para que a análise a ser realizada pelo responsável possa ser mais completa no EPA!**

**O registro de ouvidoria afora conta com o campo na aba “Parecer Unidade Notificada” : O que deve ser informado ao cliente e a opção para seleção para classificar se o atendimento foi Procedente ou Improcedente.**

**E a aba “Conclusão”, ganhou uma opção para escolher a: Classificação de Satisfação, a fim de classificar a satisfação do manifestante com a resposta retornada a ele.**

**Veja estas novas melhorias no EPA:**

**1 –** Primeiramente, você precisa acessar a edição de um registro de ouvidoria em que você é responsável. Acesse o caminho: **Política de Qualidade > Ouvidoria > Listar Atendimento.  
**

**1.1.** Acesse a aba:   ![](https://wiki.simeon.com.br/wp-content/uploads/2022/08/img_62e815a3c3129.png).

Neste ambiente um novo campo foi inserido para que o gestor responsável possa sinalizar o que deve ser respondido ao Manifestante. Veja o campo, ele fica abaixo do Parecer da Unidade notificada.

![](https://wiki.simeon.com.br/wp-content/uploads/2022/08/img_62e81802f08d8.png)

**1.2.** Ainda no ambiente de descrição do parecer da unidade notificada, uma opção foi adicionada para que o Gestor avalie se o atendimento foi procedente ou improcedente. Escolha uma opção e clique em **Salvar**. Veja:

![](https://wiki.simeon.com.br/wp-content/uploads/2022/08/img_62e81919b58d6.png)

**2 –** No registro de ouvidoria, na aba: ![](https://wiki.simeon.com.br/wp-content/uploads/2022/08/img_62e819be72b0a.png) um novo campo de Classificação também foi inserido para classificar a satisfação do manifestante com a resposta dada a ele.

Escolha uma das opções apresentadas no campo Classificação de Satisfação, este campo não é obrigatório no Registro de Ouvidoria:

Veja onde está localizado esta opção.

![](https://wiki.simeon.com.br/wp-content/uploads/2022/08/img_62e81ab8db851.png)

**3 –** As opções classificadas e listadas no campo: ⁣![](https://wiki.simeon.com.br/wp-content/uploads/2022/08/img_62e81b7cf090e.png) são configuráveis, onde você poderá criar mais opções se desejar.

**3.1.** Para criar mais opções para o campo Classificação de Satisfação, acesse o caminho: **Configuração > Política de Qualidade > Ouvidoria > Classificação de Satisfações.**

![](https://wiki.simeon.com.br/wp-content/uploads/2022/08/img_62e81c45a0121.png)

**3.2.** Neste ambiente acesse o botão:  ![](https://wiki.simeon.com.br/wp-content/uploads/2022/08/img_62e81cb21c5fc.png) e crie uma opção de **Satisfação de Atendimento**.

-   -   -   Insira uma Descrição, Nota, selecione opção Ativo e selecione se esta opção deve Considerar no Cálculo ou não.

![](https://wiki.simeon.com.br/wp-content/uploads/2022/08/img_62e81d5ebb79e.png)

**3.3.** Na listagem aparecerá as classificações de Satisfação do Atendimento criadas, veja:

![](https://wiki.simeon.com.br/wp-content/uploads/2022/08/img_62e81eef7cc27.png)

# **OBSERVAÇÃO:**

![](https://wiki.simeon.com.br/wp-content/uploads/2022/06/img_62a0ad6cb970e-300x284.png)

-   -   -   **_A opção: Considerar no Cálculo, localizada no ambiente de Classificação de Satisfações de Atendimento, ainda não está sendo utilizada neste módulo no EPA._**
    -    
        -   **_Em breve, melhorias serão aplicadas com o uso desta opção. Aguarde as próximas versões do EPA._**
