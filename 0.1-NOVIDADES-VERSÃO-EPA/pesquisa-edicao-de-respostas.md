# Pesquisa – Edição de respostas
**![](https://wiki.simeon.com.br/wp-content/uploads/2022/06/Imagens-Engracado-PNG-e-Vetor_-com-Fundo-Transparente-Para-Download-Gratis-_-Pngtree-removebg-preview-164x300.png)**

**Nessa versão, o formulário de edição das respostas das pesquisas foi modificado.**

**Agora, os usuários com permissão para edição e exclusão das respostas ao acessar o formulário para edição, o EPA apresenta o próprio formulário de respostas da pesquisa.**

**Com essa melhoria, além de edição e exclusão de respostas, será possível também  editar e inserir anexos na respectiva resposta do respondente analisado.**

**1 –** Acesse o ambiente no módulo de pesquisas para _**Visualizar as Respostas individuais,** pelo caminho:_

**_Portal >  Pesquisas >  Clicar em Resultados/Visualizar de uma pesquisa._**

![](https://wiki.simeon.com.br/wp-content/uploads/2022/06/img_62a747299ebed.png)

**2 –** Na página de apresentação de dados das respostas, clique em: Visualizar Resposta Individual. No presente botão: ![](https://wiki.simeon.com.br/wp-content/uploads/2022/06/img_62a747ea12e54.png).

![](https://wiki.simeon.com.br/wp-content/uploads/2022/06/img_62a747c2d42ed.png)

**3 –** No ambiente para **Visualizar Respostas Individuais**, quando editar uma resposta de um respondente da pesquisa, o EPA abrirá o próprio formulário utilizado no momento de inserir as respostas. Veja:

**3.1.** Para editar as respostas de um respondente:

![](https://wiki.simeon.com.br/wp-content/uploads/2022/06/img_62a749b8e95c8.png)

⇓

Para salvar novos itens no formulário, é só inserir as novas informações, seleção de opções, acompanhamentos ou anexos. O EPA irá salvar conforme as alterações forem realizadas, não sendo necessário clicar em um botão Salvar.

![](https://wiki.simeon.com.br/wp-content/uploads/2022/06/img_62a74a487b948.png)

**3.2.** Para excluir a resposta de um respondente:

![](https://wiki.simeon.com.br/wp-content/uploads/2022/06/img_62a74bdd069c9.png)

**3.3.** Para inserir ou remover anexos de uma resposta, acesse o formulário de resposta:

![](https://wiki.simeon.com.br/wp-content/uploads/2022/06/img_62a74c5371c87.png)

⇓

![](https://wiki.simeon.com.br/wp-content/uploads/2022/06/img_62a74de22de67.png)
