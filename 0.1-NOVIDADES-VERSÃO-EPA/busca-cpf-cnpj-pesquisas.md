# Pesquisas- Busca pelo participante por CPF ou CNPJ
![](https://wiki.simeon.com.br/wp-content/uploads/2022/06/Imagens-Engracado-PNG-e-Vetor_-com-Fundo-Transparente-Para-Download-Gratis-_-Pngtree-removebg-preview-164x300.png)

**Nesta versão, o campo para pesquisa de cliente/participante em dois ambientes do módulo de pesquisas ganharam uma melhoria!**

**Na página para ver as respostas individuais e a página direcionadora para responder uma pesquisa de forma manual no EPA o campo para pesquisar Cliente agora aceita a busca pelo número de CNPJ ou CPF.**

**Utilize esse novo facilitador para busca de dados no módulo de pesquisas no EPA!**

Veja como está essa nova melhoria no EPA:

**PORTAL > COMUNIACAÇÃO > PESQUISAS**

![](https://wiki.simeon.com.br/wp-content/uploads/2022/08/img_62e80e0e99f84.png)

**2 –** Após acessar o ambiente das pesquisas escolha uma de suas pesquisas em que deseja responder manualmente e clique no botão: ![](https://wiki.simeon.com.br/wp-content/uploads/2022/08/img_62e7fd6aad941.png).

Veja:

![](https://wiki.simeon.com.br/wp-content/uploads/2022/08/img_62e7fda65aff3.png)

Após isso, pesquise pelo cliente desejado a partir de seu número **CPF ou CNPJ** sem inserção de caracteres adicionais como: (,.-).

E siga com o processo para responder à pesquisa no EPA.

![](https://wiki.simeon.com.br/wp-content/uploads/2022/08/img_62e801feda67a.png)

**3 –** Outro local onde você poderá pesquisar por CNPJ ou CPF por um cliente/participante é nos relatórios de buscas de respostas individuais de uma pesquisa.
