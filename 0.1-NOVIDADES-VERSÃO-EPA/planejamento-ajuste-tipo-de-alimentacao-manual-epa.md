# Planejamento –  Ajuste tipo de alimentação manual EPA
Principais Alterações:

-   A configuração -> Tipo de alimentação Manual, foi ajustada para que somente ela, faça a liberação dos botões de acesso para alimentação de forma Manual no EPA.

-   Os demais tipos de alimentação não irão liberar os botões para alimentação manual no Sistema.
-   A configuração: _**Este indicador será alimentado automaticamente ou através de fórmula**_, também foi ajustado, agora ele somente ativa a configuração para alimentação do indicador que será por fórmula. Somente a função: _**“Este indicador será alimentado através de fórmula”**_
