# Usuários – Filtro UEN em configuração de permissões nas Unidades Gerenciais do Usuário.
![](https://wiki.simeon.com.br/wp-content/uploads/2022/06/Imagens-Engracado-PNG-e-Vetor_-com-Fundo-Transparente-Para-Download-Gratis-_-Pngtree-removebg-preview-164x300.png)

**Olá,**

**Nesta versão criamos um filtro chamado UEN, no ambiente de concessão de permissões às unidades gerenciais de um usuário no EPA.**

**Assim você conseguirá filtrar por unidades gerenciais do sistema em que deseja conceder ou modificar a permissão de acesso dos usuários/logins do EPA a partir de Unidades Estratégicas de Negócio que você tem acesso.**

Veja como utilizar essa nova funcionalidade no EPA:

**1 –** Primeiramente, acesse o ambiente: Gerenciar Usuários a partir do caminho: **Configuração> Usuários> Gerenciar Usuários**.

Após isso escolha um usuário em que deseja acessar suas permissões de acesso, clicando no botão Engrenagem: ![](https://wiki.simeon.com.br/wp-content/uploads/2022/07/img_62e3d6436f856.png)

Veja:

![](https://wiki.simeon.com.br/wp-content/uploads/2022/07/img_62e3d6a0f4087.png)

**2 –** Quando você acessar a página de configuração de Permissões de Usuário, acesse a aba: ![](https://wiki.simeon.com.br/wp-content/uploads/2022/07/img_62e3d6f3d2c49.png).

**2.1.** Neste ambiente você encontrará o filtro de UEN, este filtro apresentará como opções de escolha _SOMENTE_ as **_Unidades Estratégicas de negócio em_** que você possui acesso, ou seja, as unidades gerenciais que o usuário logado se **COMUNICA** no sistema. Veja:

![](https://wiki.simeon.com.br/wp-content/uploads/2022/07/img_62e3dde32a5bc.png)

**⇓**

![](https://wiki.simeon.com.br/wp-content/uploads/2022/07/img_62e3e50d859a9.png)

**2.2.** O filtro UEN  trará selecionado **como padrão** a unidade estratégica de negócio que o usuário selecionado para configuração possui como padrão.

Em alguns casos, a unidade gerencial padrão do usuário é uma unidade “filha” de uma UEN, assim o filtro trará selecionado como padrão a UEN em que a unidade gerencial padrão do usuário participa. Veja:

![](https://wiki.simeon.com.br/wp-content/uploads/2022/07/img_62e3e3252b010.png)

**2.3.** A  partir destas orientações, pesquise por UEN no momento de configurar permissões de unidades gerenciais para um usuário e conceda ou remova acesso entre as unidades gerenciais listadas resultantes da pesquisa no filtro.

![](https://wiki.simeon.com.br/wp-content/uploads/2022/07/img_62e3e7ffee271.png)

**3 –** Você também poderá utilizar este filtro UEN, no momento de configurações  de permissões sobre Unidades Gerenciais, nos Perfis de Usuário cadastrados no EPA.

**3.1.** Acesse e edite um perfil e usuário pelo seguinte caminho: **Configuração> Usuários> Perfil de Usuário.** Veja:

![](https://wiki.simeon.com.br/wp-content/uploads/2022/07/img_62e3e9e7a510c.png)

**3.2.** Quando você acessar a página de configuração de um Perfil de Usuário, acesse a aba: ![](https://wiki.simeon.com.br/wp-content/uploads/2022/07/img_62e3d6f3d2c49.png).

-   -   -   Neste ambiente você encontrará o filtro de UEN, este filtro apresentará como opções de escolha _SOMENTE_ as **_Unidades Estratégicas de Negócio em_** que você possui acesso, ou seja, as unidades gerenciais que o usuário logado se **COMUNICA** no sistema.
    -    
        -   O diferencial é que o filtro UEN nos perfis de usuário, não traz selecionado nenhuma unidade estratégica de negócio como Padrão.
    -    
        -   A  partir destas orientações, pesquise por UEN no momento de configurar permissões de unidades gerenciais para um perfil e conceda ou remova acesso entre as unidades gerenciais listadas resultantes da pesquisa no filtro.

![](https://wiki.simeon.com.br/wp-content/uploads/2022/07/img_62e3edcc83185.png)

**4 –**Utilize o filtro de UEN (Unidades Estratégicas de Negócio) para auxiliar no processo de configuração de permissões das unidades gerenciais entre os usuários e perfis de usuários no EPA.

**![](https://wiki.simeon.com.br/wp-content/uploads/2022/05/a38addc0469bb9b9bb45550042634c6d-247x300.jpg)**
