# **Projetos

-   _**Novas telas de Cadastro de informações básicas para uso em projetos no EPA.**_ 
    -   Esta versão o EPA novos ambientes para cadastro básicos de algumas informações que serão utilizadas no módulo de projetos no EPA.
    -   Vale Ressaltar que a integração e uso destas só serão possíveis em próximas versões do sistema, pois outras melhorias estão sendo trabalhadas no momento.

-   -   -   As telas de cadastro são das seguintes informações:                 **_Filiais_**

                             _**Tipos de Pagamentos**_  
                             _**Modalidades de Apoio Financeiro**_
