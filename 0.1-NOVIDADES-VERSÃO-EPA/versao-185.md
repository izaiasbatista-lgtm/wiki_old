**Release 185.1:**

**Tela Principal**  
Foi adicionada uma nova funcionalidade à tela do responsável pela avaliação de eficácia que exibe a quantidade de dias restantes conforme a configuração de data definida no sistema. Esta atualização permitirá ao responsável visualizar de forma clara e precisa o período ativo para a realização da avaliação, além de identificar quando o prazo estipulado foi ultrapassado.

**Planejamento – Análise Crítica**  
 Foi implementada uma nova funcionalidade que garante que, ao selecionar um indicador para apresentação na análise crítica, o sistema considere também aqueles indicadores que, embora não possuam dados de alvo e resultado informados para o período, contenham anotações ou análises de desempenho relevantes.

**Planejamento – Indicador**  
**1-**No módulo Indicadores, foi efetuada uma alteração no símbolo utilizado para identificar a situação de “não houve registro nesta etapa”. Anteriormente representado por um símbolo específico, agora essa condição será indicada pelo caractere **“-“**

**2-**  Foi implementada uma nova funcionalidade no módulo de Indicadores que introduz uma mensagem de alerta ao alterar o alvo. A mensagem informa ao usuário que a alteração afetará a etapa atual e, se necessário, oferece a opção de aplicar a mudança em todas as etapas.

**Pessoas – Treinamento**  
**1-**  Foi introduzida uma nova funcionalidade no sistema para otimizar o processo de confirmação de presença em treinamentos. Agora, é possível gerar uma lista de presença que inclui apenas os participantes marcados como “presentes” no checkbox “Participou”.

**2-** Foi adicionada novas variáveis no campo de certificado, facilitando a personalização dos certificados segundo as informações específicas de cada evento. Agora, é possível usar variáveis como **#nome do palestrante**, **#data de treinamento** e **#local** para adaptar os certificados de forma mais eficiente e personalizada.

**3-**  Agora, o sistema impede que um usuário se inscreva em mais de uma turma do mesmo treinamento simultaneamente. Se o usuário tentar se inscrever em uma nova turma para um treinamento no qual já está registrado, será exibido um alerta informando sobre a inscrição existente e oferecendo a opção de cancelar a inscrição atual para prosseguir com a nova.

**Portal – Pesquisa**  
Foi implementada uma nova funcionalidade no módulo de pesquisas para assegurar total anonimato ao responder pesquisas. Quando a opção **“Resposta com único usuário (usuário geral para evitar identificação)”** é selecionada, a pesquisa será realizada de forma completamente anônima pelo **QR CODE**, garantindo que os usuários não possam se identificar.

**Portal – Armário Virtual**

 Foi realizado um ajuste no campo de visualização do nome no módulo **Armário Virtual/Anexo** para aumentar a quantidade de caracteres exibidos. Essa atualização permite uma visualização mais completa dos nomes, facilitando a identificação e o gerenciamento dos arquivos e documentos.

**Trilha de Auditoria**  
 Foi implementado um limite de 30 dias no filtro da trilha de auditoria, restringindo a exibição dos registros a um período de até 30 dias por vez. Essa atualização proporciona um controle mais eficiente sobre a visualização dos dados auditados, garantindo que as informações sejam exibidas de forma mais gerenciável e precisa.

**Parametrização – Pessoas**  
Foi introduzida uma nova permissão no sistema denominada **“Analista de Pessoas”**, que reflete as Unidades Estratégicas de Negócio (UENs) às quais o analista tem acesso. Esta permissão permite que os analistas visualizem, gerenciem e realizem atividades específicas dentro das UENs associadas, garantindo que suas operações sejam restritas aos dados pertinentes às respectivas unidades.

**Pesquisa Avançada**

**1-**  A partir de agora, ao editar e salvar uma avaliação, um e-mail de feedback 1-1 será enviado automaticamente, sobrepondo as permissões de envio de e-mail previamente configuradas.

**2-**  Criação de categorias de feedback tanto na parametrização de pessoas quanto na pesquisa avançada. Essa atualização proporciona uma melhor organização e filtragem das categorias de feedback, permitindo uma gestão mais eficiente das informações.
