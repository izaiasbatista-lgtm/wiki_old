# Logo das UEN’S nos formulários de uso externo
**![](https://wiki.simeon.com.br/wp-content/uploads/2022/06/Imagens-Engracado-PNG-e-Vetor_-com-Fundo-Transparente-Para-Download-Gratis-_-Pngtree-removebg-preview-164x300.png)**

**Como configurar logo nas UEN’S da empresa para os formulários de uso externo.**

> Nessa versão o EPA disponibiliza a opção para configurar logos personalizadas por empresa no sistema.

**1- Para saber como configurar para apresentar no e-mail a logo conforme a UEN, acesse o artigo:**[**  
Como configurar logo para a UEN**](https://wiki.simeon.com.br/configuracao-uen-e-mails-novidade-de-versao-164/)

![](https://wiki.simeon.com.br/wp-content/uploads/2022/11/img_636a98d2485ca.png)

Essa configuração refletirá nos e-mails que serão enviados a partir dos módulos de **reuniões, solicitações, ouvidoria e ocorrências**.

**Ouvidoria:** Agora, no EPA com esta configuração da logo da UEN será disponibilizada nos formulários para uso externo. O sistema faz uma análise de hierarquia para disponibilizar o formulário com a logo:  
→ 1.° unidade gerencial padrão do usuário;  
→ 2.º se a unidade é uma UEN;  
→ 3.º se já tem uma logo configurada, cumprindo esses requisitos a logo será apresentada no formulário externo. 

Caso não tenha uma UEN, o sistema irá olhar para cima hierarquicamente, olhando assim pro pai da unidade a fim de encontrar alguma UEN. Sendo que, não seja encontrada será apresentada a logo padrão do sistema.
