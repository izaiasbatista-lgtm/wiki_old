# Projetos – Novas opções para configuração de Projeto no EPA.
![](https://wiki.simeon.com.br/wp-content/uploads/2022/06/Imagens-Engracado-PNG-e-Vetor_-com-Fundo-Transparente-Para-Download-Gratis-_-Pngtree-removebg-preview-164x300.png)

**Nessa versão o módulo de Projetos ganhou opções configuráveis para ativar ou não algumas funcionalidades do módulo.**

**Com isso, você poderá configurar de forma individual e personalizada em seus projetos, quais os ambientes e acessos que realmente ele deve ter.**

**Por exemplo,  a opção Gerenciar Custos, caso desmarcada, não mostra nada de Custo no Planejamento, Execução, Monitoramento e edição das tarefas.**

Veja como utilizar essa nova configuração!

**1 –** Acesse o ambiente de projetos e crie um projeto no EPA, pelo caminho: _**Projetos> Gestão de Projeto> Incluir projeto.  
**_

**2 –** Na página de inclusão de um novo projeto, você verá as novas opções para poder escolher conforme a necessidade do projeto. Veja:

![](https://wiki.simeon.com.br/wp-content/uploads/2022/06/img_6299f81322cc0.png)

**3 –** Veja o que as novas caixinhas para seleção liberam no projeto:

-   -   **3.1. ( ) Acompanhar Termo de Abertura:**
        -   Esta opção libera no projeto a aba **Termo de abertura** e seus **Relatórios**.

![](https://wiki.simeon.com.br/wp-content/uploads/2022/06/img_629a00e9a2306.png)
