# Planejamento – Data Limite para inserir uma Análise de Desempenho dos Indicadores
**![](https://wiki.simeon.com.br/wp-content/uploads/2023/05/depositphotos_38689733-stock-photo-giraffe.webp)**

**Neste artigo, vamos falar sobre uma nova atualização do sistema, que traz uma importante funcionalidade para garantir o cumprimento de prazos na análise de desempenho dos indicadores. A partir de agora, será possível estabelecer uma data limite para a inclusão e edição da análise de desempenho, com o objetivo de garantir maior rigor e pontualidade no processo de atualização.**

Para configurar essa nova melhoria, acesse: **Parametrização → Planejamento → Configurar Etapa.**

**Veja:**

![](https://wiki.simeon.com.br/wp-content/uploads/2025/04/img_67f40fb9bb958.png)

Agora, em **Etapas**, escolha aquela na qual deseja definir uma data limite para que o usuário realize a análise de desempenho. Em seguida, clique em **Editar**, conforme mostrado na imagem a seguir:

**Veja:**

![](https://wiki.simeon.com.br/wp-content/uploads/2025/04/img_67f411ac206a3.png)

Em configurar etapas, vamos ver a  nova opção **“Data Limite para inserir uma Análise de Desempenho”.** Ao definir uma data, clique em salvar.

**Veja:**

![](https://wiki.simeon.com.br/wp-content/uploads/2025/04/img_67f41398b0947.png)

As alterações descritas a seguir serão aplicadas **somente** se for estabelecida uma data limite. Caso contrário, o sistema continuará funcionando como antes, levando em consideração apenas a data de fechamento.

Quando estiver dentro do prazo, a tela de Análise de Desempenho exibirá um alerta com a seguinte mensagem: **“O indicador ainda não atingiu o desempenho esperado, o que deseja fazer?”**, além do botão **Adicionar Análise**, conforme ilustrado a seguir:

**Veja:**

![](https://wiki.simeon.com.br/wp-content/uploads/2025/04/img_67f41b5a2eda9.png)

Quando a Data Limite para inserir uma análise de desempenho for excedido, a tela não exibirá o alerta, nem o botão **Adicionar Análise**, conforme ilustrado a seguir:

**Veja:**

![](https://wiki.simeon.com.br/wp-content/uploads/2025/04/img_67f41c17edfb0.png)

Ao adicionar uma análise dentro do prazo, o usuário poderá editá-la até a data limite definida. Após o vencimento desse prazo, será possível apenas excluí-la.
