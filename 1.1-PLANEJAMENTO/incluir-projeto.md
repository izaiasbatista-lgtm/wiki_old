# Incluir Projeto
Para **incluir** novo projeto acesse o menu **Projetos>Gestão de Projetos**.

Na tela de gestão de projetos, clique no botão  ![](https://wiki.simeon.com.br/wp-content/uploads/2019/12/img_5df7e3289a890.png) para incluir um novo projeto.

![](https://wiki.simeon.com.br/wp-content/uploads/2019/12/img_5df7e41c8f1c3.png)

Será aberta a tela do projeto.

          Informe o **Título do projeto** (1), a **unidade gerencia**l (2) e o **gestor do projeto** (3) e clique no botão SALVAR (4).

![](https://wiki.simeon.com.br/wp-content/uploads/2019/12/img_5df7e3ca89025.png)

          Será aberta a tela abaixo. Preencha os campos da tela conforme a identificação informada e clique no botão SALVAR (1).

![](https://wiki.simeon.com.br/wp-content/uploads/2019/12/img_5df7eb2deff62.png)

Preencha os campos conforme abaixo:

**Título do Projeto:** Identificação do projeto na organização.

**Código:** Codificação do projeto segundo padrão da organização. O EPA sugere um código sequencial para o projeto, que pode ser alterado conforme definição na organização.

**Tipo:** Agrupamento macro, pré definido, ao qual o projeto está relacionado.

**Unidade Gerencial:** Área gestora do projeto.

**Prioridade:** Prioridade estabelecida para o projeto dentro da organização ou área ou departamento.

**Categoria:** Agrupamento, pré definido, que especifica a categoria do projeto.

**Objetivo Geral do Projeto:** Informe de forma resumida o objetivo do projeto.

**Cliente:** Informe o cliente que será atendido com a execução do projeto. O EPA pesquisará o nome informado no cadastro de pessoas físicas, jurídicas ou funcionários do EPA.  _Esse campo não é obrigatório._

**Data Limite Conclusão Projeto:** Informe a data definida para a conclusão do projeto. O sistema sinalizará as tarefas com datas que ultrapassem a data de conclusão definida para o projeto.

**Nº Contrato/Processo:** Informe o número de um contrato ou processo ao qual o projeto esteja vinculado, caso exista.

Projeto Corporativo:  Essa opção é usada para sinalizar que um projeto prioritário na organização. Ao marcar essa opção
