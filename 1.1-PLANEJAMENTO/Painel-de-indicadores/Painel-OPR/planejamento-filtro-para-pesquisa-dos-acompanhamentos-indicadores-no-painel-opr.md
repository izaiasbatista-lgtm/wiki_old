# Planejamento – Filtro de datas para os acompanhamentos no Painel OPR
> **Nessa versão, no Painel OPR implementamos filtros de datas para realização de pesquisas dos acompanhamentos já registrados nos indicadores apresentados!**
> 
> **Com os campos de filtros de datas você terá mais autonomia, para pesquisar os acompanhamentos que desejar, e ainda apresentá-lo se necessário no relatório gerado em PDF no Painel OPR.**
> 
> **Veja essa novidade!**

**1 –** Acesse o Painel OPR:

_Caminho: Planejamento> Painel OPR>  Vá até o local dos acompanhamentos !_

**2 –** Você poderá ver o botão com opção para visualizar e utilizar os novos filtros de datas para suas pesquisas dos acompanhamentos do indicadores:

Clique nele para visualização dos filtros de datas. Veja o botão na imagem a seguir:

![](https://wiki.simeon.com.br/wp-content/uploads/2021/01/img_601404bf91576.png)

**3 –** Os filtros estarão disponíveis para utilização, estes irão trazer como resultados padrão, datas e acompanhamentos dos últimos três meses em relação a etapa selecionada.

Como mostra as datas dos filtros data inicio e data fim na imagem abaixo.  Altere as datas para ver outros acompanhamentos dos indicadores de outras datas.

![](https://wiki.simeon.com.br/wp-content/uploads/2021/01/img_6014037985c80.png)

**4 –**  Os acompanhamentos apresentados no Painel OPR, com as respectivas datas selecionadas nos filtros também serão apresentados no relatório exportado juntamente com todas as informações do Painel OPR !

![](https://wiki.simeon.com.br/wp-content/uploads/2020/06/img_5eecbdba05736.png)

**Lembrando que os acompanhamentos registrados no Painel OPR, são os mesmos acompanhamentos que são registrados no detalhamento de um indicador. Ambos serão apresentados tanto no painel OPR e também no acompanhamento do indicador.**

**Veja o tutorial para acesso e configuração do Painel OPR**:  [https://wiki.simeon.com.br/painel-de-indicadores-painel-opr/](https://wiki.simeon.com.br/painel-de-indicadores-painel-opr/)
