# Planejamento – Incluir Perspectiva
Para **incluir** as perspectiva definidas no mapa estratégico a imagem do planejamento no menu do EPA clique no ícone ![](https://wiki.simeon.com.br/wp-content/uploads/2018/05/img_5af988f898c5d.png) **Planejamento > Incluir Perspectiva.**

![](https://wiki.simeon.com.br/wp-content/uploads/2018/09/img_5ba8f48b6f967.png)

Para incluir uma perspectiva informe no campo **Ordem** **(1)** a sequência de apresentação da perspectiva no painel de indicadores, escreva a identificação da perspectiva no campo **Perspectiva** **(2)** e clique no botão **Salvar (3)**. 

Os perspectivas existentes serão apresentadas na **Lista de Perspectivas (4)**.

Para excluir uma perspectiva clique no botão ![](https://wiki.simeon.com.br/wp-content/uploads/2018/11/img_5bdb3cbbd31bf.png) **(5)**.
