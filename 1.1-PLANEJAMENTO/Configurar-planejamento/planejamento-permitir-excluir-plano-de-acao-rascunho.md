# Planejamento – Permitir excluir plano de ação (rascunho)
**![](https://wiki.simeon.com.br/wp-content/uploads/2023/05/depositphotos_38689733-stock-photo-giraffe.webp)**

**Neste artigo, vamos apresentar um guia passo a passo sobre como excluir um plano de ação ao qual o usuário tem acesso.**

Para realizar essa ação, o usuário precisará de uma permissão específica. Para concedê-la, siga os seguintes passos: clique em **Parametrização → Usuário → Gerenciar Usuário.** 

**Veja:**

![](https://wiki.simeon.com.br/wp-content/uploads/2025/03/img_67daf694eb664.png)

Ao selecionar o usuário desejado, acesse a seção de Planejamento e, em seguida, marque a opção **Permitir exclusão do plano de ação** para conceder ao usuário a permissão de excluir o plano de ação que ele tem acesso.
