# Planejamento – Listagem de Critérios e SubCriterios quando configurados
![](https://wiki.simeon.com.br/wp-content/uploads/2021/06/giraffe-e1623062804726-169x300.png)

**Nessa versão, ajustamos a forma de selecionar os critérios e subcritérios  no formulário de alimentação do indicador de forma Manual.**

> -   -   -   -   -   **Agora, quando existir critérios configurados, o sistema irá apresentá-los para que você possa escolher em caixas de seleção, obedecendo os diferentes níveis existentes dos subcritérios .**
>             -    
>                 -   **A partir de então, cada nível de subcritério possui uma caixa de seleção apresentada para que você possa escolher qual é o critério desejado para informar na alimentação.**
>             -    
>                 -   **Assim você poderá escolher uma opção de critério e o sistema direcionará para a sua escolha.** **Com essa melhoria podemos minimizar as chances de erro ao selecionar um critério.**

Veja como está a nova forma de seleção:

**1 –**  Primeiramente, nas configurações do indicador que possui alimentação de forma **Manual**, é preciso que ele tenha critérios e até mesmo subcritério configurado.  Acesse as configurações do indicador escolhido.

Na aba critérios, você pode criar, editar e remover critérios e subcritérios.

Veja também que em alguns casos ele segue uma estrutura de hierarquia, como no exemplo abaixo.

Acesse: _**Planejamento> painel de indicadores> configuração do indicador escolhido**_:

![](https://wiki.simeon.com.br/wp-content/uploads/2021/06/img_60d1d78a57396.png)

⇓

![](https://wiki.simeon.com.br/wp-content/uploads/2021/06/img_60d1d7e107eee.png)

**2 –** Assim quando for alimentar de forma manual esse indicador, o sistema trará para você da seguinte forma o formulário para preenchimento:

-   -   -   -   Selecione o primeiro critério desejado para a alimentação do indicador:

![](https://wiki.simeon.com.br/wp-content/uploads/2021/06/img_60d0da6121a08.png)

-   -   -   Ao selecionar o 1° critério, o sistema apresentará a próxima caixa de seleção com os subcritérios disponíveis para próxima seleção, veja:

![](https://wiki.simeon.com.br/wp-content/uploads/2021/06/img_60d0e0127e377.png)

-   -   -   -   Após selecionar o subcritério, se houver cadastrado no sistema um próximo subcritério, o sistema apresentará a nova caixa de seleção para escolha.

![](https://wiki.simeon.com.br/wp-content/uploads/2021/06/img_60d0dfea8c862.png)

![](https://wiki.simeon.com.br/wp-content/uploads/2021/06/img_60ccb49e1ca6e-138x300.png)

Após escolher os critérios e subcritérios desejados, é só preencher os demais campos para a alimentação, como: **_Data, Valor, colaborador e Salvar._**
