# Planejamento – Boas práticas para montar uma planilha para importar resultado para o indicador
Ao montar uma planilha em Excel para subir valor ou alvo para o indicador, deve-se atentar a alguns pontos:

-   Certifique-se de que a planilha não possui formatação. Se houver, limpe antes de importar.
-    Verifique se a coluna de data está no formato Data abreviada **(dd/mm/yyyy)** e se as datas estão dentro do período correto, evitando lançamentos no mês errado.
-   Mantenha a ordem das colunas exatamente conforme o padrão de importação do EPA.
-   Utilize apenas uma aba na planilha, pois o EPA considera somente a primeira.
-   Confirme se o código do indicador está correto.
-   Não insira fórmulas ou funções. O EPA lê apenas valores estáticos.
-   Nas colunas de Critério (Critério 1, Critério 2, Critério 3…), os campos são do tipo texto. O sistema não interpreta formatos aplicados no Excel, como R$, pontos ou vírgulas de milhar.  
    O sistema considera somente o que está escrito dentro da célula. Por exemplo, se no Excel consta R$ 6,00 o sistema enxergará apenas 6.  
    Por isso, deixe os valores sem formatação para garantir a leitura correta dos dados e evitar erros de importação.
