# Planejamento – Como alimentar o indicador manual
**_![](https://wiki.simeon.com.br/wp-content/uploads/2023/07/img_64a80189e6620.png)_**

**  
Neste artigo vamos mostrar o passo a passo para alimentar o indicador manual.**

**Atenção: Antes de iniciar, segue algumas observações importantes sobre permissões para alimentar indicador:**

**1-** O usuário que vai alimentar o indicador, precisa estar configurado no indicador como **Responsável Alimentação** ou **Responsável Análise** na **etapa** que vai alimentar. Ou então ter a permissão de **Super usuário,** para conseguir alimentar o indicador que ele não é responsável.

![](https://wiki.simeon.com.br/wp-content/uploads/2021/07/img_60fb0c838251a.png)

**2-** Na configuração do indicador na aba configurações gerais, no campo **Tipo de alimentação** deve estar selecionada a opção **Manual**.

![](https://wiki.simeon.com.br/wp-content/uploads/2021/07/img_60fb0c2e13e92.png)

Agora vamos ao passo a passo de como alimentar o indicador manual!  
Acesse o painel de indicadores e clique com o botão esquerdo do mouse **em cima do nome do indicador(1)**, no exemplo abaixo vamos alimentar o indicador Compras.

![](https://wiki.simeon.com.br/wp-content/uploads/2021/07/img_60fb3ba7217e8.png)

Será carregada a tela de detalhamento do indicador, certifique que a etapa selecionada é a que precisa alimentar e clique no botão ![](https://wiki.simeon.com.br/wp-content/uploads/2020/10/img_5f861748d05e3.png) **(2)**  para abrir a tela para incluir valor no indicador.

![](https://wiki.simeon.com.br/wp-content/uploads/2021/07/img_60fb3d1695f7d.png)

A tela de incluir valor pode mudar os campos de acordo com a operação selecionada no indicador, segue a forma que será apresentada a tela para incluir o valor do indicador de acordo com cada operação.

-   **Soma, Média aritmética**

> Se for **Soma****:**  soma do campo valor de cada item inserido para compor o resultado do indicador. _  
> Calculo : (valor A + valor B + valor C + valor D), exemplo: (1+3+5+7)  
> _Se for **Média aritmética:**  soma do campo valor de cada item inserido para compor o resultado do indicador  dividido pelo total de itens inseridos._  
> Calculo : (valor A + valor B + valor C + valor D) / qtde de valores lançados, exemplo: (1+3+5+7+9)/5_  

A tela será apresentada conforme a imagem abaixo, ao lançar o valor se for necessário ajuste a **data(3)** referente ao mês que vai alimentar o indicador, informe o **valor(4)** que será alimentado.  A tela será apresentada dessa forma:

![](https://wiki.simeon.com.br/wp-content/uploads/2021/07/img_60fb41f553f9d.png)

Se o valor a ser alimentado for um dado de um colaborador, informe o usuário dele no campo **Colaborador(5),** caso não seja pode deixar em branco. Abaixo serão listados os **critérios (6)** que cadastrou no seu indicador, no exemplo acima o indicador tem dois critérios, então vou inserir as informações pertinentes a cada campo referente ao valor que vou alimentar. Em todas as operações a forma de preencher os critérios será a mesma.

Caso queria incluir outros valores clique em **salvar incluir outro(8)** para salvar e a tela carregar com os campos em branco para inserir novos dados, ou clique em **salvar(9)** para finalizar.

-    **Ponderada e **Calcular média aritmética do peso****

> Se for  ****média ponderada** :**Soma da multiplicação do campo valor de cada item inserido para compor o resultado do indicador, pelo respectivo número informado no campo peso, dividido pela soma dos pesos de cada item.  
> _Calculo: ( valor x peso do valor ) / (soma dos pesos), exemplo: (1x(5)+3x(2)+5x(5))/12_
> 
> E se for **Calcular média aritmética do peso:** Soma do campo valor de cada item inserido dividido pela soma  dos pesos de cada item.  
> _Calculo: (soma dos valores) / ( soma dos pesos), exemplo: (1+3+5)/(5+2+5)= 9/12  
> _

Nas duas opções de cálculo precisa que seja informado o **Peso(10)**, a tela será apresentada a tela dessa forma:

![](https://wiki.simeon.com.br/wp-content/uploads/2021/07/img_60ff0c4840e9a.png)

-   **Executar divisão dos valores no cálculo do resultado**.Fator de multiplicação****

> Se for **Executar divisão dos valores no cálculo do resultado**.Fator de multiplicação****,  é divisão do valor informados no campo numerador pelo valor informado no campo denominador, de cada item multiplicado por um fator (100, 1000, etc).  
> _Calculo: (soma numeradores/soma denominadores x fator de multiplicação, exemplo: (6/5) x 100_

O fator de multiplicação deve ser informado na configuração do indicador, e o **numerador (11)** e **denominador (12)** será informado ao incluir o valor no indicador.  
A tela será apresentada a tela dessa forma:

![](https://wiki.simeon.com.br/wp-content/uploads/2021/07/img_60ff0b6d8793a.png)
