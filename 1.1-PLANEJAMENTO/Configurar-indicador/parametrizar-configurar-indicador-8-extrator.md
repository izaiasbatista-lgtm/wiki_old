# Planejamento – Parametrizar / Configurar indicador – 8 – Extrator
![](https://wiki.simeon.com.br/wp-content/uploads/2019/12/img_5df7cbdf905af.png)

**VÍNCULO VIA EXTRATOR DE DADOS EPA**

Nesta aba é feito o relacionamento  do campo filho, informado na rotina 10 e 28 do extrator, aos indicadores que receberão os resultados retornados pela consulta de extração de dados. 

**_No extrator de dados o código do indicador deverá ser o mesmo do indicador no qual estão sendo relacionados os indicadores que receberão os resultados passados pelo campo filho._**

**Informe parte do nome ou o código do indicador que deseja vincular\\:** Informe o nome do indicador que será relacionado ao indicador em configuração. O indicador pode estar em qualquer unidade gerencial e não precisa estar relacionado como filho do indicador em configuração. 

 **–**  ![](https://wiki.simeon.com.br/wp-content/uploads/2019/12/img_5df7cffbd8953.png)**:** Clique no botão Pesquisar para buscar os indicadores desejados (1) . Os indicadores com títulos correspondentes serão listados abaixo.

 **–** ![](https://wiki.simeon.com.br/wp-content/uploads/2019/12/img_5df7ceba6124a.png): Marque os indicadores desejados.

 **–** ![](https://wiki.simeon.com.br/wp-content/uploads/2019/12/img_5df7cf0c6d144.png): Digite o valor que será retornado na variável campo filho correspondente ao indicador selecionado.

 **–** ![](https://wiki.simeon.com.br/wp-content/uploads/2019/12/img_5df7cf648f6bd.png): Clique no botão Salvar para gravar o relacionamento feito.

Os indicadores já vinculados serão listados na tela (2).

VÍNCULO VIA WEB SERVICE

**Informe a url do webservice que você deseja fazer integração:** Informe o endereço para conexão com o Web Service. Na tela estão listados os campos de retorno esperados do web service.
