# Planejamento – Parametrizar / Configurar indicador – 7 – Fórmulas
Para que a aba de **Fórmulas** seja habilitada no indicador, é necessário que nas Configurações Gerais a opção **Este indicador será alimentado através de fórmula** precisa estar marcada.

![](https://wiki.simeon.com.br/wp-content/uploads/2023/11/img_654a738cce0f0.png)

Na aba **Fórmulas** é permitido realizar cálculos com o resultado de outros indicadores existentes. Segue o passo a passo de como realizar a configuração dos campos para utilizar esse recurso:

![](https://wiki.simeon.com.br/wp-content/uploads/2021/07/img_61007b904f9c7.png)

**1-** No campo **Etapa (1):** Informe a etapa  na qual a fórmula estará ativa.

**2-** No campo **Fórmula  Ex.: (A-B)/A  (2):** Informe a fórmula a ser executada.  Operações permitidas (soma (+), subtração (-), divisão (/), multiplicação (\*).

**3-** No campo **Etapa origem(3):** Escolha em qual etapa a fórmula estará ativa.  
Quando é informado Atual o EPA considerará para formar o resultado a etapa correspondente ao período calculado. Exemplo: Etapa do indicador atualizado igual a janeiro, serão considerados no cálculo os resultados inseridos em janeiro.   
Quando é informado uma etapa específica, o EPA considerará para formar o resultado na etapa informada. Exemplo: Etapa do indicador atualizado igual a janeiro e etapas escolhidas Dez/2018, serão considerados no cálculo os resultados inseridos em Dez/2018.

**4-** No campo **Apelido Ex. A.  (4):** Informe o apelido do indicador para identificá-lo na fórmula a ser informada.

**5-** No campo **Indicador  (5):** Informe o código do indicador que será identificado pelo apelido ou clique no botão ![](https://wiki.simeon.com.br/wp-content/uploads/2019/12/img_5df7c76842cfd.png) para pesquisar o indicador.

**6-** Após informar o apelido e código do indicador, marque a opção **Alterar fórmula para todas as etapas com permissão para alterar configuração(6)** para parametrizar a fórmula em todas as etapas existentes.

**7-** Caso queria aplicar a fórmula ao alvo marque a opção **Aplicar fórmula para calcular o alvo (7)**, ao marcar essa opção serão considerados os valores informados como alvo dos indicadores. Depois clique no botão **Incluir Formula(8)** para incluir a variável.

**8-** Repita o processo informado o apelido e o código do indicador, para todos os indicadores que compõe a fórmula e depois clique em **Salvar**.  
Quando for incluindo, as variáveis serão listadas na tela.

Caso queira excluir a fórmula das etapas escolhidas clique no botão **Limpar Fórmula(9).**
