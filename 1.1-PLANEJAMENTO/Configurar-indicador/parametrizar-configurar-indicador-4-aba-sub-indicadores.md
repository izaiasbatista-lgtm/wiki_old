# Planejamento – Parametrizar / Configurar indicador – 4 – Aba Sub indicadores
**Nesta tela do EPA será possível vincular indicadores para formar uma estrutura de árvore.** 

![](https://wiki.simeon.com.br/wp-content/uploads/2019/11/img_5dd59e3403f62.png)

Para vincular os indicadores será necessário localizar o indicador, para tanto informe :

**Componente de desempenho**: selecione o componente de desempenho a onde o indicador será localizado,

**Unidade gerencial**: selecione a unidade gerencial do indicador,

**Etapa**: selecione a etapa na qual o indicador está ativo,

**Pesquisar por nome ou código**: informe o código ou o nome do indicador a ser relacionado.

Clique no botão **Pesquisar** para efetuar a pesquisa.

Os indicadores que corresponderem ao filtro serão listados na tela **(1)**  para serem selecionados pelo usuário. Para vincular o indicador o usuário deve seleciona-lo e clicar no botão **Salvar**. 

Os indicadores vinculados serão listados na seção _**Indicadores inseridos (Sub indicadores)**_ 

Para **EXCLUIR** o vinculo clique no botão ![](https://wiki.simeon.com.br/wp-content/uploads/2019/11/img_5dd5a3a5c11cc.png) do sub indicador a ser desvinculado. O vínculo será desfeito e na tela serão listados somente os indicadores vinculados. 

> ![](https://wiki.simeon.com.br/wp-content/uploads/2021/05/img_60930786cba6d.png)**Atenção!** Quando a opção **Excluir sub indicador em todas as etapas com permissão de alterar** **configuração** não estiver marcada o vinculo será desfeito somente na etapa padrão atual.
