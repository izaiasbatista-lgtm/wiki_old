# Planejamento – Como configurar meus indicadores na tela principal do EPA.
![](https://wiki.simeon.com.br/wp-content/uploads/2022/06/Imagens-Engracado-PNG-e-Vetor_-com-Fundo-Transparente-Para-Download-Gratis-_-Pngtree-removebg-preview-164x300.png)

 **Indicadores apresentados na tela principal do EPA.**

![](https://wiki.simeon.com.br/wp-content/uploads/2023/02/img_63ddbd3733311.png)

> **1\.** Primeiro passo, configure a permissão para o usuário nas > Permissões gerais > Planejamento > Mostrar meus indicadores na tela principal.
> 
> ![](https://wiki.simeon.com.br/wp-content/uploads/2023/02/img_63ddb148b75ae.png)

        **2\.** Os indicadores que serão apresentados na tela principal do EPA são os da unidade gerencial padrão do usuário.

         Caso o usuário seja um gestor de mais de uma unidade gerencial, o mesmo só irá visualizar os indicadores da sua unidade padrão. Assim, vale também para os usuários que tem mais de uma unidade, os indicadores que irão apresentar são os da sua ****unidade gerencial padrão.****

      **3.** O EPA apresenta na tela principal os indicadores, considerados mais importantes para o usuário.

-     A regra da ordem de como os indicadores serão apresentados é de acordo com uma filtragem que o EPA faz;

       a. Verifica quais indicadores o usuário é responsável.

       b. Verifica os indicadores com peso mais alto.

       c. Verifica quais indicadores não estão com alvos vazios.

       d.  Verifica os indicadores que já possuem resultado.

       e. Verifica a descrição dos indicadores por ordem alfabética.  

-   O total de indicadores apresentados nesta funcionalidade é sempre> 9 (nove).

    **4.** Ainda que o indicador seja disponibilizado para uma unidade padrão do usuário, o mesmo entrará para a filtragem do EPA, tendo que seguir os critérios conforme o **item 3.**

![](https://wiki.simeon.com.br/wp-content/uploads/2023/02/img_63ddbb44c4576.png)

-   Obs: O EPA irá apresentar sempre os indicadores do primeiro planejamento estratégico que esteja ativo.  
    Exemplo: Foi criado o planejamento estratégico em 2022, o EPA estará apresentando os indicadores referente a este planejamento, no momento em que é criado um planejamento para 2023, o planejamento de 2022 terá que ser inativado, para o EPA considerar o planejamento de 2023 e apresente os indicadores na tela principal.

-   O EPA realiza essa filtragem e ordena os indicadores com maior relevância para o usuário conseguir visualizá-los melhor na sua tela principal. Sendo que, alvos que estejam vazios, sem responsável, não possuam resultados são critérios que irá desclassificar seu indicador de se apresentar na tela principal.
