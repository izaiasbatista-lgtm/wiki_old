# Planejamento  –  Extrator WEB Indicadores
> **Nessa versão, foram implementadas algumas melhorias no Extrator WEB do EPA.**
> 
> **Agora no extrator você conseguirá pesquisar os indicadores pelo nome e também pelo seu número (código).**
> 
> **O layout também foi ajustado para uma melhor experiência com a usabilidade nas ações disponíveis no Extrator.**

Veja as melhorias!

**1.** Acesse: _**Planejamento> Funcionalidade > Extrator EPA.**_

**1.1.** Um novo campo foi inserido para poder pesquisar entre a listagem de todos os indicadores, um indicador.

Nessa pesquisa você poderá pesquisar o **indicador pelo nome** ou pelo **código.**

_Veja o novo campo:_

![](https://wiki.simeon.com.br/wp-content/uploads/2021/05/img_6091835376f4e.png)

**1.2.** Pesquise um de seus indicadores pelo nome ou código, o extrator trará o resultado conforme digitar:

![](https://wiki.simeon.com.br/wp-content/uploads/2021/05/img_609183fcc509e.png)

 **2.** O layout foi melhor ajustado para receber as ações disponíveis no extrator, veja como está organizado as funcionalidades agora:

_**2.1.** Data inicio e Data fim para sincronização;_

_**2.2.** botão de ação para sincronizar todos os indicadores;_

_**2.3.** Botão ação pra reagendar Sincronizações no extrator;_

_**2.4.** Campo para pesquisar indicadores pelo nome ou código;_

_**2.5.** Campo Seleção das classificações cadastradas no extrator;_

_**2.6.** Listagem dos indicadores automatizados no extrator._
