# Cadastro de Pessoas – Exibição do Prontuário/Código do Atendimento
**![](https://wiki.simeon.com.br/wp-content/uploads/2023/05/depositphotos_38689733-stock-photo-giraffe.webp)**

**Nesse artigo vamos falar sobre a parametrização “Exibir o prontuário/código do atendimento no cadastro de pessoas”, utilizada para controlar a visibilidade desse campo no cadastro.**

Ao acessar a aba de **“Parametrização”** tem as opções **“Sim”** e **“Não” para exibir o prontuário/código do atendimento no cadastro de pessoas**. O valor padrão é **“Não”**, mantendo o sistema com o funcionamento atual.

**Veja:**

![](https://wiki.simeon.com.br/wp-content/uploads/2025/09/img_68bec2c4eddce.png)

Ao habilitar a parametrização (**Sim**), o usuário pode:

-   Vincular uma nova **Unidade Gerencial**;
    
-   Editar manualmente o campo **“Prontuário/Código do Atendimento”**;
    
-   Consultar a coluna **“Unidade Gerencial”**, que mostra o caminho completo da unidade;
    
-   Utilizar o botão de ações, que contém apenas a opção **“Excluir”** para remoção de vínculos.
    

**Veja:**

![](https://wiki.simeon.com.br/wp-content/uploads/2025/09/img_68bec4fe623ee.png)

Com essa parametrização, o sistema oferece maior flexibilidade no gerenciamento das informações de cada pessoa, permitindo que o usuário controle a visibilidade do **prontuário/código do atendimento** e acompanhe de forma clara os vínculos com as unidades de origem. Dessa forma, é possível manter os dados organizados, facilitar a edição quando necessário e garantir que as informações estejam sempre acessíveis de maneira estruturada.
