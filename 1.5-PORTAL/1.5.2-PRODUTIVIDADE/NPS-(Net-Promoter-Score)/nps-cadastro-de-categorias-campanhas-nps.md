# NPS – Cadastro de Categorias Campanhas NPS
> **Nessa versão a funcionalidade NPS ganhou mais uma funcionalidade para facilitar o gerenciamento das campanhas NPS.**
> 
> **Agora será possível cadastrar tipos de categorias NPS, para serem inseridas no momento do cadastro das campanhas, assim você conseguirá separar e gerenciar suas campanhas NPS no EPA, por tais categorias.**

Veja como configurar:

**Cadastro de Categorias NPS**

**1 –** Para o cadastro de Categorias NPS, você precisa **ativar** a permissão para a tela de configuração:

Acesse: _Configuração> Usuários > Gerenciar Usuários> Menu: Configurações>_

_(**Parametrização> Portal> NPS> Cadastro Categoria NPS).**_

![](https://wiki.simeon.com.br/wp-content/uploads/2021/05/img_60a2a4bdeb9be.png)

**2 –** Após ativar a permissão, acesse a página de **cadastro das categorias NPS.** Acesse _Configuração> Portal> NPS> Cadastro Categorias NPS. Veja:_

![](https://wiki.simeon.com.br/wp-content/uploads/2021/05/img_60a2a74e61672.png)

**3 –** Na tela de cadastro de NPS, você poderá:

**3.1.** Criar novas categorias NPS,

**3.2.** Editar as Categorias NPS,

**3.3.** Excluir uma categoria NPS já cadastrada, (Lembrando que só é possível excluir uma campanha que não esteja sendo usada nas campanhas NPS).

Veja a tela para cadastro:

![](https://wiki.simeon.com.br/wp-content/uploads/2021/05/img_60a2aaa02c33c.png)

**4 –** Após cadastrar as categorias NPS, ao criar uma campanha NPS ou editar alguma existente, você poderá selecionar uma categoria NPS que esteja Ativa para identificar uma campanha.

-   -   Acesse _Portal> NPS> Campanhas_.
    -   **Crie ou edite** uma campanha NPS e na tela de informações básicas, veja como selecionar uma categoria para campanha NPS:

![](https://wiki.simeon.com.br/wp-content/uploads/2021/05/img_60a2ada9dbb11.png)

Ambiente criar uma campanha NPS

**5 –**  Assim, as campanhas do EPA passam a ter suas próprias categorias, na tela de inicial de listagem das campanhas NPS cadastradas no EPA, você poderá filtrar e pesquisar campanhas a partir de suas categorias.

Ainda em:  **_Portal> NPS> Campanhas_.**

Veja os novos filtros que você poderá utilizar para pesquisar as campanhas NPS no EPA.

**Filtros de:**

-   -   **_Categoria_:** neste filtro o Epa apresentará as categorias ativas e inativas cadastradas no EPA para pesquisar campanhas,
-    
    -   **_Unidade Gerencial:_** este filtros apresentará as unidades gerenciais que você tem a permissão de Comunica no EPA, para pesquisar suas campanhas.
-    
    -   **_Data inicio e Data fim:_** pesquisa campanhas de data inicio e fim no EPA.

![](https://wiki.simeon.com.br/wp-content/uploads/2021/05/img_60a3c24cd32bf.png)

Aproveite essa nova melhoria!
