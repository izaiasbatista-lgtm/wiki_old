# Configurar Pesquisa NPS em Tablet
-   **Configurar Usuário Tablet**

Para conseguir responder a pesquisa NPS no tablet, deve ser criado um usuário de checklist que irá responder as pesquisas.  
Esse usuário deve ter a permissão **_Usuário específico para responder pesquisas (checklist, NPS, tablet),_** para que quando acesse o EPA seja direcionado apenas para a tela dos questionários. E a permissão **_Responder Pesquisa Como Outro Usuário_** para que apareça a opção para conseguir identificar o paciente no momento em que for responder a pesquisa.

![](https://wiki.simeon.com.br/wp-content/uploads/2020/04/img_5eab223a26931.png)

> **IMPORTANTE**: Para cada mobile (tablet/celular) precisa ter um usuário diferente para responder a pesquisa, e esses usuários não podem responder ao mesmo tempo.

-   **Liberar acesso do usuário para responder o questionário**

Após criar o questionário deve ser liberada a permissão no questionário de NPS, no botão **Permitir Acesso (1)**  marcando as opções  **Acesso as Respostas e** **Cadastro da Pesquisa .  
**

![](https://wiki.simeon.com.br/wp-content/uploads/2020/01/img_5e172f6985cc9.png)

E a campanha de NPS deve estar ativa, e no período vigente informado no campo **Data Início da Campanha**  e **Data Fim da Campanha (2).  
**

![](https://wiki.simeon.com.br/wp-content/uploads/2020/01/img_5e172ed23690b.png)

-   **Respondendo a Pesquisa**

Quando acessar o EPA com o usuário configurado no tablet, será listada os questionários que ele tem acesso e a opção para lançar a reposta.

![](https://wiki.simeon.com.br/wp-content/uploads/2020/02/img_5e5678d164e00.png)

Se foi marcada a permissão **_Responder Pesquisa Como Outro Usuário_**  para o usuário, quando ele clicar para responder a pesquisa vai aparecer uma caixinha para que seja informado alguns dados do cliente.  
Caso o respondente seja um usuário do EPA pode ser informado no campo usuário **(3)**, informe a data que foi realizada a avaliação **(4),**  informe a unidade gerencial que foi aplicada a avaliação **(5).  
**Se caso seja um paciente/cliente e ele deseja se identificar marque a opção _**Solicitar identificação ao final do questionário?**_ **(6),** essa opção libera um campo no final da pesquisa para que o paciente/cliente informe seu nome, email e celular.

Caso deseje cadastrar o paciente clique na opção cadastrar paciente **(7)** será aberta uma nova tela para cadastrar cliente, e ao clicar em Responder questionário o usuário será direcionado para responder a pesquisa.  
Lembrando que todos os campos nessa tela não são obrigatórios.

![](https://wiki.simeon.com.br/wp-content/uploads/2020/02/img_5e567b21e92dd.png)

Ao terminar de responder a pesquisa caso tenha marcado a opção _**Solicitar identificação ao final do questionário?**_, será aberta uma nova aba solicitando os dados do paciente.

![](https://wiki.simeon.com.br/wp-content/uploads/2020/02/img_5e567d1ecd46f.png)
