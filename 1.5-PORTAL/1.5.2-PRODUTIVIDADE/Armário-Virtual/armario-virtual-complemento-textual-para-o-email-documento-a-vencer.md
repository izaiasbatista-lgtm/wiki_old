# Armário Virtual – Complemento Textual para o email: Documento a vencer
> **Nessa versão um novo parâmetro foi inserido no sistema para uso no módulo do Armário Virtual, com ele você poderá complementar o texto padrão apresentado no  email que é enviado para informar que em breve um documento de sua responsabilidade irá vencer.**
> 
> **No Parâmetro você poderá informar um conteúdo em texto para ser apresentado juntamente com o texto padrão.**

Veja como configurar:

**1 –** Acesse: _Configuração> Parametrização do Sistema._

Selecione no menu: **Armário Virtual:**

![](https://wiki.simeon.com.br/wp-content/uploads/2020/12/img_5fe240854a94f.png)

**2 –** Você encontrará o parâmetro: “**Insira aqui o texto que deve aparecer logo após as informações de expiração de documento do armário virtual na notificação por email”.**

No Campo valor insira qual é o texto que você deseja apresentar como complemento das informações padrões no email enviado sobre a notificação de vencimento.

![](https://wiki.simeon.com.br/wp-content/uploads/2020/12/img_5fe2423894c23.png)

![](https://wiki.simeon.com.br/wp-content/uploads/2020/06/img_5eecbdba05736.png)

> \-> O texto padrão que já é enviado neste email de notificação de vencimento dos documentos do armário virtual é:
> 
> **Prezado Gestor,
> **      **Informamos que o documento**  NOME DO DOCUMENTO**, estará vencendo em** DATA VENCIMENTO  **(DIAS** **dia(s))**

**3 –** Veja como é o email: **Documento a Vencer** do Armário Virtual:

O texto padrão vem primeiramente, logo após o texto informado no parâmetro é apresentado.

![](https://wiki.simeon.com.br/wp-content/uploads/2020/12/img_5fe24968b0296.png)

**4 –** Caso não queira utilizar o texto complemento configurado no novo parâmetro para o email, é só deixar o campo do parâmetro valor vazio:

![](https://wiki.simeon.com.br/wp-content/uploads/2020/12/img_5fe24bcc01bc1.png)

> **Qualquer Dúvida estamos a disposição.![](https://wiki.simeon.com.br/wp-content/uploads/2020/07/logo-epa.png)**
