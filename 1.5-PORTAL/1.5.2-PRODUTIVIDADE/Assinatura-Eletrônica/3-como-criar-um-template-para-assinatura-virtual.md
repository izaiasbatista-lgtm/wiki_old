# 3- Como Criar um Template para Assinatura Virtual
**![](https://wiki.simeon.com.br/wp-content/uploads/2023/05/depositphotos_38689733-stock-photo-giraffe.webp)**

**Como Criar um Template para um Documento para Assinatura Virtual**

  Para simplificar o processo de criação de uma nova assinatura, oferecemos a opção de usar um ”Template” que irá criar como modelo de documento. Com essa funcionalidade, você pode adaptar as informações em um documento para que fique pronto para assinatura.

Aqui estão os passos para criar um **”template”**:

\-> Passo 1: Clique em ”**Criar Template**” e adicione um título ao seu modelo de documento.

\-> Passo 2: ”**Na descrição”**, insira as informações que compõem o seu documento e em seguida clique em salvar.

Por exemplo, se o seu documento é um contrato, adicione as informações genéricas do contrato. Isso permitirá que, mais tarde, quem utilizar o modelo apenas edite as informações e ajuste os dados conforme necessário.

Exemplo;

![](https://wiki.simeon.com.br/wp-content/uploads/2024/01/img_65971ee4bb899.png)

Com essa funcionalidade, tornamos o processo de preparar documentos para assinatura mais eficiente e personalizado.
