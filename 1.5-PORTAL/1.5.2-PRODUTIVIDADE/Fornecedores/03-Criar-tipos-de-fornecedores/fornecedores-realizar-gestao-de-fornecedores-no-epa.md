# Fornecedores – Realizar Gestão de fornecedores no EPA.
![](https://wiki.simeon.com.br/wp-content/uploads/2022/06/Conformidade-Fornecedores-247x300.png)![](https://wiki.simeon.com.br/wp-content/uploads/2022/06/banner_fornecedores-300x75.png)

Veja como utilizar esse novo módulo no EPA:

# **Cadastrar Fornecedores**

![](https://wiki.simeon.com.br/wp-content/uploads/2022/06/img_62acd80e15fc3.png)

**1** – Primeiramente, cadastre os seus fornecedores no EPA como: _**pessoa física, jurídica ou funcionário**_, para que você possa gerenciá-los no Módulo de Fornecedores.

Para cadastrar seus fornecedores no EPA, veja como realizar essa ação na nossa base de conhecimento, acesse na WIKI:

**Cadastro de Pessoa Física: [Cadastro de Pessoa Física.](https://wiki.simeon.com.br/cadastro-de-pessoas/)**

**Cadastro de Pessoa Jurídica: [Cadastro de Pessoa Jurídica](https://wiki.simeon.com.br/cadastro-de-pessoas/).  
**

**Cadastro de Pessoa Funcionário: [Cadastro de Funcionário.](https://wiki.simeon.com.br/cadastro-de-pessoas/)**

**Cadastro Rápido de Pessoas: [Cadastro de Funcionário.](https://wiki.simeon.com.br/cadastro-de-pessoas/)**

**Importação de Pessoas: [Artigo em Desenvolvimento](https://wiki.simeon.com.br/usuarios-importacao-de-clientes/) – Aguarde!**

-          Após cadastrar o fornecedor, acesse o artigo **[Configurar Fornecedores](https://wiki.simeon.com.br/4-cadastrar-fornecedores/),** para saber qual é o passo a passo para parametrizar o cadastro do fornecedor.

# **Publicar documentos no Armário Virtual**

![](https://wiki.simeon.com.br/wp-content/uploads/2022/06/img_62ace017c9886.png)

**2 –** O próximo passo é publicar no armário virtual no EPA, os documentos necessários relacionados aos seus Fornecedores. Estes documentos serão para compor a avaliação de conformidade de cada fornecedor configurado.

Dentre os documentos para os fornecedores estão: _Contratos, Alvarás, Certificados de Regularidade, Certificado de Controle de Qualidade e entre outros_.

Para realizar o Cadastro Básico e publicar documentos no Armário Virtual, siga os passos indicados na nossa base de conhecimento acesse:

**Cadastro Básico para uso do módulo Armário Virtual: [Cadastros Básicos Armário Virtual](https://wiki.simeon.com.br/cadastros-basicos-armario-virtual/)**

**Publicar um Documento no Armário Virtual: [Publicar um documento Armário Virtual](https://wiki.simeon.com.br/criar-um-documento-armario-virtual/)**

# **Gerenciar Vencimento de Documentos**

![](https://wiki.simeon.com.br/wp-content/uploads/2022/06/img_62ace7b7c1f51.png)

**3 –** Quando os Documentos publicados chegarem próximo à data de vencimento, a partir da configuração realizada no Tipo de documento, o EPA listará na tela principal do Gestor ou envolvido em um Box de acesso à informação para renovação do Documento.

Para realizar a renovação de documentos no Armário Virtual, siga os passos indicados na nossa base de conhecimento acesse:

**Renovar um Documento no Armário Virtual: [Renovar um documento do Armário Virtual](https://wiki.simeon.com.br/renovar-documento/)**

# **Realizar Avaliação de Fornecedores**

![](https://wiki.simeon.com.br/wp-content/uploads/2022/06/img_62ace83a04a09.png)

**4 –** O próximo passo é configurar no EPA os formulários para avaliação/pesquisa, para o início das avaliações dos Fornecedores incluídos no EPA. Um avaliador será responsável por responder essa avaliação no EPA.  

Crie as pesquisas relacionadas a avaliação dos fornecedores no sistema, veja como realizar esse passo no EPA a partir do artigo: [Pesquisas – Criar uma pesquisa/questionário no EPA](https://wiki.simeon.com.br/criar-questionario/).

Veja o exemplo de Pesquisa de Avaliação nas imagens a seguir:

![](https://wiki.simeon.com.br/wp-content/uploads/2022/06/img_62b0afb216102.png)

![](https://wiki.simeon.com.br/wp-content/uploads/2022/06/img_62b0b02b46e2d.png)

# **Monitorar Avaliação dos Fornecedores**

![](https://wiki.simeon.com.br/wp-content/uploads/2022/06/img_62ace86030670.png)

**5 –** Para acompanhar a Avaliação do Fornecedor, acesse o ambiente de resultados. Neste ambiente serão apresentadas as perguntas e resposta recebidas na avaliação com uma visualização em gráficos.

Veja como acessar a página de resultados da pesquisa de **Avaliação dos Fornecedores**, siga os passos indicados na nossa base de conhecimento, acesse:

**Cadastro Básico para uso do módulo Armário Virtual: [Visualizar os Resultados da Pesquisa](https://wiki.simeon.com.br/resultado-da-pesquisa).**

Veja o ambiente para acompanhamento das respostas:

![](https://wiki.simeon.com.br/wp-content/uploads/2022/06/img_62b0b93593025.png)

# **Monitorar  Resultado dos Fornecedores**

![](https://wiki.simeon.com.br/wp-content/uploads/2022/06/img_62ace881d68e3.png)

**6 –** Acesse o módulo de fornecedores e veja a partir de uma única página os seus fornecedores selecionados que serão avaliados em suas respectivas avaliações nas pesquisas e os documentos do armário para verificar se estes estão em conformidade com os serviços prestados ou não.

**Acesse o Painel Único de Gerenciamento dos Fornecedores: [Fornecedores – Painel Único para gerenciar os fornecedores](https://wiki.simeon.com.br/fornecedores-painel-unico-para-gerenciar-os-fornecedores/)**

**Veja como configurar Tipos de Fornecedores no EPA: [Criar Tipos de Fornecedores no EPA](https://wiki.simeon.com.br/fornecedores-criar-tipos-de-fornecedores-no-epa)**
