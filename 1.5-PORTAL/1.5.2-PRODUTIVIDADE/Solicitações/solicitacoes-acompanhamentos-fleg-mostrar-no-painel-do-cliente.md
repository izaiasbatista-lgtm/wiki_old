# Solicitações – Habilitar como padrão o acompanhamento no Painel do Cliente
> **Uma nova melhoria foi implementada para auxiliar o processo de inclusão de acompanhamentos que precisam ser mostrados no Painel do Cliente EPA.**
> 
> **Agora uma nova configuração foi  implementada, para que ao incluir novos acompanhamentos, o check: “Mostrar no Painel do cliente?” venha habilitado de forma automática.**

Para ativar essa funcionalidade, veja como configurar a seguir:

**1 –** Acesse a configuração do Tipo de solicitação em que você deseja ativar essa funcionalidade:

Acesse: Configuração > Portal > Solicitações > Tipo de solicitações > Acesse o tipo de solicitação que deseja configurar.

Ao Editar o tipo de solicitação escolhido, habilite o novo parâmetro para configuração: **Habilitar como padrão o acompanhamento no Painel do Cliente.**

Veja na imagem:

![](https://wiki.simeon.com.br/wp-content/uploads/2020/09/img_5f64f0f3417ca.png)

**2 –** Após esta configuração, todas as solicitações com este tipo de solicitação, terão habilitados de forma automatica em todos os acompanhamentos o check: **“Mostrar no Painel do cliente?”**,  para mostrar então esse acompanhamento no Painel do Cliente!

Veja:

![](https://wiki.simeon.com.br/wp-content/uploads/2020/09/img_5f64f4ecef2aa.png)
