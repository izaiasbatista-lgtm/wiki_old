# Portal – Solicitações: Base de Conhecimento (nova permissão)
![](https://wiki.simeon.com.br/wp-content/uploads/2021/07/img_60f9af23432dd-e1631299903164-213x300.png)

> **Nessa versão, criamos  uma nova permissão para o módulo de solicitações, para a funcionalidade Base de conhecimento.**
> 
> **Agora, no EPA temos uma permissão que possibilita mostrar ou não a aba: base de conhecimento ao editar uma solicitação.**
> 
> **Assim, de forma personalizada você poderá ajustar a visualização para uso dessa opção ou não para os usuários de seu departamento.**

Veja onde encontrar essa permissão para a configuração:

**1 –** Acesse: **Configuração> usuários> gerenciar usuários> (selecione o respectivo usuário para ajustar a permissão).**

**1.1.** Em permissões Gerais, encontre as permissões do módulo de solicitações e veja a permissão:

**Visualizar base de conhecimento.**

![](https://wiki.simeon.com.br/wp-content/uploads/2021/10/img_615da3155e6bd.png)

**1.2.** Assim quando a permissão **Visualizar base de conhecimento** estiver selecionada/ativa, o EPA apresentará a opção Base de Conhecimento ao editar as solicitações, veja:

![](https://wiki.simeon.com.br/wp-content/uploads/2021/10/img_615da8e17d4fa.png)

**1.3.** E quando a permissão **Visualizar base de conhecimento** não estiver selecionada/inativa, o EPA não apresentará a opção Base de Conhecimento ao editar as solicitações, veja:

![](https://wiki.simeon.com.br/wp-content/uploads/2021/10/img_615da88c0ce9c.png)
