# Solicitações – Melhorias Dashboard
**Melhorias Dashboard – Módulo de Solicitações**

– Inserido caixas para visualização de todos os Status disponíveis no filtro para pesquisar dados de solicitações.

– Configurado permissões para visualização de informações sobre as solicitações, mostradas nos gráficos do Dashboard:

-   Usuário poderá ver  informações nos gráficos sobre solicitações das unidades que ele PERTENCE,
-   Usuário poderá ver informações nos gráficos sobre solicitações das unidades que ele GERENCIA.
