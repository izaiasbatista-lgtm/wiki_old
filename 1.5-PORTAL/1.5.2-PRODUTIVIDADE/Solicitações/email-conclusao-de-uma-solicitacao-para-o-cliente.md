# Solicitações – Email Conclusão de uma solicitação para o Cliente.
**Email Conclusão de uma solicitação para o Cliente.**

> **Agora é possível configurar através de um Parâmetro no sistema, para que o cliente inserido em informações básicas ao incluir uma solicitação, receba um email o notificando quando esta solicitação for concluída.**

Vá até: Configurações > Parametrização do sistema.

![](https://wiki.simeon.com.br/wp-content/uploads/2020/05/img_5ec2d39a5eee3.png)

Selecione no Menu: Solicitações,

Logo após vá até o parâmetro selecionado conforme a imagem e configure o para **Sim.**

![](https://wiki.simeon.com.br/wp-content/uploads/2020/05/img_5ec2d4dc01797.png)

**Atenção:**  Após configurar o parâmetro no cadastro do cliente marque a opção **Receber e-mail/ Gostaria de receber email**, caso essa opção esteja desmarcado o EPA não enviará o email para o cliente. 

![](https://wiki.simeon.com.br/wp-content/uploads/2020/07/img_5efe26239a91b.png)

![](https://wiki.simeon.com.br/wp-content/uploads/2020/07/img_5efe252227f2f.png)

Qualquer dúvida ou sugestão de melhorias, estamos a disposição!
