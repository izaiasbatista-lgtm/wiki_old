# Solicitações-  Incluir novos clientes a partir da configuração de Assinaturas Eletrônicas.
**![](https://wiki.simeon.com.br/wp-content/uploads/2022/06/Imagens-Engracado-PNG-e-Vetor_-com-Fundo-Transparente-Para-Download-Gratis-_-Pngtree-removebg-preview-1-164x300.png)**

**Nessa Versão adicionamos a possibilidade de inclusão de um novo signatário, durante a configuração do processo de assinaturas no documento selecionado.**

**Com isso, o processo de inclusão de signatários ganha mais um facilitador e você não terá que sair da tela de configuração das assinaturas para registrar um novo cliente no EPA.**

**Aproveite o uso dessa funcionalidade!**

Veja como utilizar essa nova funcionalidade!

**1 –** Acesse a solicitação em que terá o documento para disparo de Assinatura Eletrônica, aos signatários a serem configurados.

E acesse o ambiente de configuração das assinaturas eletrônicas.

Para saber mais sobre como configurar assinaturas digitais, acesse: [Solicitação: Assinatura Eletrônica nos documentos em anexo](https://wiki.simeon.com.br/portal-assinatura-digital-nos-documentos-em-anexo-de-uma-solicitacao/)

![](https://wiki.simeon.com.br/wp-content/uploads/2022/06/img_629f8b68ba49f.png)

**2 –** Acessando o campo para configurações de signatários no documento, você encontrará o novo botão:  ![](https://wiki.simeon.com.br/wp-content/uploads/2022/06/img_629f8c07d6cbe.png). A partir dele você conseguirá criar novos clientes no sistema e além disso já adicioná-los na lista para disparo da Assinatura Eletrônica.

**2.1.** Clique no botão: **+Adicionar Signatário,** e preencha os campos necessários para criar o novo cliente.

![](https://wiki.simeon.com.br/wp-content/uploads/2022/06/img_629f8d41300b5.png)

**2.2.** Preencha os campos necessários para criação do novo cliente no EPA. Ao finalizar, clique em **salvar**.  Veja a seguir:

![](https://wiki.simeon.com.br/wp-content/uploads/2022/06/img_629f8e417d173.png)

**2.3.** O EPA irá salvar o novo cliente no sistema e também já inseri-lo na listagem para o futuro disparo da Assinatura Eletrônica.

Siga com os demais passos para realização do processo de inclusão de novos signatários se necessário e dispare a ação para as assinaturas.

![](https://wiki.simeon.com.br/wp-content/uploads/2022/06/img_629f8fa031f33.png)

**2.4.** O cliente registrado neste ambiente estará disponível no sistema para uso em outros cenários, basta pesquisar por ele, veja:

![](https://wiki.simeon.com.br/wp-content/uploads/2022/06/img_629f914e83aba.png)

**2.5.** Para voltar para a tela de pesquisa de signatários já cadastrados no EPA, é só clicar no botão:

![](https://wiki.simeon.com.br/wp-content/uploads/2022/06/img_629f94290e896.png)
