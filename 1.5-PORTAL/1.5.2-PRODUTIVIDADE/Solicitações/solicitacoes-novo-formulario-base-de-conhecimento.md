# Solicitações – Base de conhecimento
![](https://wiki.simeon.com.br/wp-content/uploads/2021/06/giraffe-e1623062804726-169x300.png)

Nessa Versão as solicitações no EPA ganharam mais uma funcionalidade: **A base de conhecimento**!

-   -   **Agora em uma Solicitação, você conseguirá registrar novas soluções, tutoriais e informações importantes em uma nova aba no formulário de uma solicitação.**
-    
    -   **Com essa Melhoria, além de inserir novas soluções para alimentar a base de conhecimento da solicitação, é possível também pesquisar por soluções que foram incluídas por outros usuários.**
-    
    -   **Assim você poderá pesquisar por processos, tutoriais, soluções realizadas sobre o mesmo tipo de solicitação/serviço e criar novas publicações para auxiliar os demais usuários no EPA.**

> _Veja como utilizar essa novidade no EPA!_

### **BASE DE CONHECIMENTO – SOLICITAÇÕES**

**1 –** Acesse qualquer solicitação e veja a nova aba: “**Base de conhecimento”.**

Acesse essa aba e nela você poderá ver as soluções/publicações já criadas em outras solicitações por usuários no EPA.

 ![](https://wiki.simeon.com.br/wp-content/uploads/2021/07/base-de-conhecimento.png)

**2 –** Neste ambiente da base de conhecimento da solicitação, você poderá **criar novas publicações**, **editar** ou **excluir** publicações que foram criadas por você e **pesquisar por publicações** existentes utilizando os filtros disponíveis. Veja:

**2.1.** Criar publicação;

**2.2.** Pesquisar por publicações já registradas, com os filtros de tipo de serviço ou palavras chave.

**2.3.** Editar ou excluir uma publicação.

![](https://wiki.simeon.com.br/wp-content/uploads/2021/07/img_60f03814770f2.png)

---

> ### **COMO CRIAR NOVAS PUBLICAÇÕES?**

**3 –** Para você criar novas publicações em uma solicitação, inicialmente você precisa possuir permissão de acesso ativa para esse fim, para que o botão  de inclusão seja habilitado em seu acesso.

As permissões que permitem esse acesso são: **_Permitir incluir e alterar base de conhecimento_** e _**Super Usuário.**_

![](https://wiki.simeon.com.br/wp-content/uploads/2021/07/img_60f038c64e17e.png)

**4 –** Você poderá criar novas publicações/soluções para a base de conhecimento a partir de dois locais:

**4.1.** Criar uma publicação dentro de uma solicitação, na aba Base de conhecimento.

-   -   -   -   -   _Clique no **botão +**,_
            -    
                -   _Escreva sua publicação no campo disponível,_
            -    
                -   _Ao finalizar clique em **Salvar**._

Veja:

![](https://wiki.simeon.com.br/wp-content/uploads/2021/07/img_60f03a62595d2.png)

**4.2.** Criar uma publicação, a partir da configuração de um tipo de solicitação no EPA.

Acessando: Configuração> portal> solicitações> tipos de solicitações> Editando um tipo de solicitação. Veja a imagem a seguir:

![](https://wiki.simeon.com.br/wp-content/uploads/2021/07/img_60f03cc230fed.png)

-   -   _**Edite** um tipo de solicitação,_
-    
    -   _Acesse a aba: **Base de Conhecimento**,_
-    
    -   _Clique no **botão +**,_
-    
    -   _Escreva sua publicação no campo disponível,_
-    
    -   _**Campo Opcional**: selecione um Tipo de Serviço para vincular a postagem da base de conhecimento a ela, essa ação não é obrigatória. Se porventura, não fizer parte do processo, não será necessário vincular nenhum Tipo de Serviço a postagem, o sistema vai processar e salvar da mesma forma._
-    
    -   _Ao finalizar clique em **Salvar**._

Veja: 

![](https://wiki.simeon.com.br/wp-content/uploads/2021/07/img_60f03c7c021b6.png)

![](https://wiki.simeon.com.br/wp-content/uploads/2021/06/img_60ccb49e1ca6e-138x300.png)

> _**IMPORTANTE:**_

-   Quando você **criar uma publicação** a partir de uma **solicitação** na aba: Base de Conhecimento, essa publicação **será vinculada ao Tipo de Serviço** correspondente a atual solicitação.

-   Caso queira criar uma publicação a partir do **acesso das configuração de um tipo de solicitação no EPA**, você **poderá escolher** se deseja vincular a um Tipo de Serviço ou não. 

-   Você terá a opção para ocultar no menu da solicitação a opção base de conhecimento! Para essa ação, acesse as configurações de permissões dos respectivos usuários em: **Configuração> Usuários> Gerenciar Usuários.** 

Em Permissões Gerais, desmarque a permissão:

![](https://wiki.simeon.com.br/wp-content/uploads/2021/10/img_615d9e0f25a26.png)

---

> ### **LISTAGEM E PESQUISAS NA BASE DE CONHECIMENTO**

**5 –** A base de conhecimento, irá exibir as publicações criadas dentro das solicitações através de seus tipos de solicitação!

**5.1.** Pesquise por publicações que foram vinculadas ou não à um tipo de serviço da solicitação;

**5.2.** Se precisar pesquise também por publicações/soluções a partir de palavras chaves.

Veja a seguir:

![](https://wiki.simeon.com.br/wp-content/uploads/2021/07/img_60f04195e64a6.png)

_As mesmas publicações serão exibidas na base de conhecimento, independente do caminho utilizado para o acesso._
