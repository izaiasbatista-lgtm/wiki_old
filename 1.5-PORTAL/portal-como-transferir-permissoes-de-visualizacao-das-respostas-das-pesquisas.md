# Portal – Como transferir permissões das pesquisas
**![](https://wiki.simeon.com.br/wp-content/uploads/2023/05/depositphotos_38689733-stock-photo-giraffe.webp)**

**Nesse artigo, vamos explicar como funciona a transferência de todas as permissões das pesquisas no Portal, recurso que facilita a continuidade do acompanhamento das atividades quando elas são transferidas de um usuário para outro.**

Para acessar a tela de transferência, siga o caminho:

**Parametrização → Usuários → Gerenciar Usuário → Usuário → Transferir.**

**Veja:**

![](https://wiki.simeon.com.br/wp-content/uploads/2025/06/img_683db50c26ef7.png)

Nessa tela, você verá uma nova opção chamada “**Transferir todas as permissões das pesquisas”**.

**Veja:**

![](https://wiki.simeon.com.br/wp-content/uploads/2025/06/img_683db5a2ebd3a.png)

Ao selecionar essa opção, o novo usuário para quem as atividades estão sendo transferidas receberá automaticamente todas as permissões das pesquisas atribuídas ao usuário de origem, que, por sua vez, será desvinculado de todas elas e perderá o acesso.

![](https://wiki.simeon.com.br/wp-content/uploads/2025/03/img_67c87b79c4bf5.png)
