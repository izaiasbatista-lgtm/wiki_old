# Portal – Novidade de Versão 165
![](https://wiki.simeon.com.br/wp-content/uploads/2022/06/Imagens-Engracado-PNG-e-Vetor_-com-Fundo-Transparente-Para-Download-Gratis-_-Pngtree-removebg-preview-164x300.png)

**Veja as principais alterações da versão 165 em Portal.**

**Portal > Comunicação> Pesquisas** 

-   _**Melhoria para definir, alterar e visualizar as permissões de acesso às configurações de pesquisas no EPA.**_

Esta versão conta com uma melhoria na edição de uma pesquisa, uma nova aba chamada: **Permitir Acesso,** esta foi criada para que você possa definir as permissões de acesso aos respectivos a uma pesquisa.

Nesta aba você terá a listagem dos usuários já definidos para a permissão, facilitando a pesquisa, manutenção de acesso e visualização das informações e respectivas permissões dos usuários.

Edite uma pesquisa no EPA em: _**Portal> Comunicação> Pesquisas.**_

![](https://wiki.simeon.com.br/wp-content/uploads/2022/12/img_639cb96a8e828.png)

_**Veja o novo ambiente de acompanhamento de Evolução das Campanhas NPS no EPA:**_

O EPA ganhou um ambiente para que você consiga acompanhar a evolução das pesquisas NPS disparadas pelo EPA.

A página evolução NPS, tem o objetivo de apresentar os resultados por participantes sobre as últimas campanhas NPS disparada pelo EPA. A funcionalidade possui um filtro que através dele você conseguirá filtrar os questionários disponíveis, e selecionando 1 pesquisa, você poderá verificar a evolução das respostas dos participantes que responderam a campanha.

**Acesse: Portal> Produtividade> NPS > Evolução NPS:**

**Portal > Comunicação> Mensagem  
**

_**O módulo de Mensagens no EPA ganhou integração com a funcionalidade de Feliz Aniversário:**_

Agora os usuários do EPA poderão ser notificados com a felicitação de feliz aniversário a partir do módulo de mensagens!

-    
    -   No dia do seu Aniversário, chegará uma mensagem no EPA via respectivo módulo. A mensagem apresentará também o Cartão de feliz aniversário, configurado na Parametrização do EPA.
-    
    -   Outra novidade é que os acompanhamentos inseridos pelos colegas no post de feliz aniversário da tela principal do EPA, também chegarão como e-mails no módulo de mensagens.
-    
    -   Assim quando for aniversário de um usuário do EPA, este, poderá ver as felicitações recebidas pelos colegas, mesmo que seja em um final de semana. Todas as mensagens serão direcionadas ao módulo de Mensagens do sistema.

_**Melhorias para o módulo de fornecedores:**_

-   -   Nesta versão algumas melhorias foram adicionadas para o módulo de Fornecedores!
-    
    -    A primeira delas, é que agora a parametrização de um fornecedor no formulário do cliente (fornecedor) só poderá ser acessado caso o usuário seja o Gestor do tipo de Fornecedor.

 Acesse os tipos de fornecedores  cadastrados no EPA e defina quem serão os Gestores por tipo. Assim quando o respectivo gestor do tipo acessar o formulário pessoa de um fornecedor, conseguirá acessar e configurar as abas:

-   -   **Parametrizar Fornecedor,**
    -   **Qualificação de fornecedor,**
    -   **Bloqueio de Fornecedor**
-    
    -   O Gestor por tipo ao acessar o formulário pessoa do fornecedor, verá somente os tipos de fornecedor e demais informações dos tipos que ele é gestor.

# Atenção:

![](https://wiki.simeon.com.br/wp-content/uploads/2022/08/rodeo-e1662764238671-254x300.png)

-   **Cálculo da avaliação:**  O cálculo segue o mesmo padrão definido em versões anteriores, é realizados média aritmética entre as últimas respostas recebidas a cada avaliação entre as unidades gerenciais na pesquisa.

-   **Parametrização dos avaliadores de fornecedores já definidos no EPA:** foi aplicado no EPA para que os avaliadores já configurados para os fornecedores no EPA recebam junto a parametrização sua Unidade gerencial padrão.

-   **Notificação das avaliações aos avaliadores:** nos box de acesso na tela principal do EPA, o avaliador receberá o acesso para responder a pesquisa de acordo com a unidade gerencial configurada para avaliação.

-   **Formulário de Respostas ao avaliador (questionário) :** As pesquisas utilizadas nas avaliações dos fornecedores, serão sempre para gravar uma nova resposta (nvezes). A página para responder a avaliação, ao acessa-la sempre será apresentada como nova e sem respostas anteriores.

**Novo Dashboard – para acompanhamento de dados dos Fornecedores:**

Nesta versão, foi adicionado um Dashboard para o módulo de fornecedores no EPA, Nele você poderá analisar os dados deste módulo a partir de apresentações em gráficos!

-    
    -   Os gráficos apresentados no dashboard do módulo de fornecedores, respeitam o uso dos filtros disponíveis na página, trazendo assim uma busca mais direcionada.
-    
    -   O Dashboard contempla os seguintes gráficos:

-   -   -   **Fornecedores por Tipos de Fornecedor**

-   -   -   -   Apresenta os top 20 tipos de Fornecedores com mais fornecedores cadastrados;

-   -   -   **Fornecedores por Tipos de Documentos**

-   -   -   -   Apresenta os top 20 tipos de Documentos com mais fornecedores cadastrados;

-   -   -   **Fornecedores por Avaliador** 

-   -   -   -   Apresenta os top 20 avaliadores com mais fornecedores cadastrados;

-   -   -   **Fornecedores por Responsável**

-   -   -   -   Apresenta os top 20 responsáveis com mais fornecedores;
