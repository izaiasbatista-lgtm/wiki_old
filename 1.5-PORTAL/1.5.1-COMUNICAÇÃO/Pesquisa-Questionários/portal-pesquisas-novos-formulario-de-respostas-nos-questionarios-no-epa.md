# Pesquisas: Configuração para uso de um mesmo link de acesso ao questionário entre os participantes.
![](https://wiki.simeon.com.br/wp-content/uploads/2022/06/Imagens-Engracado-PNG-e-Vetor_-com-Fundo-Transparente-Para-Download-Gratis-_-Pngtree-removebg-preview-164x300.png)

-   **Configuração para uso de um mesmo link de acesso ao questionário entre os participantes.**

Nessa versão, remodelamos uma configuração nos questionários de pesquisa do EPA, para que os respondentes ao acessar um questionário, possa responder o mesmo link, quando necessário.  

Com a configuração ativa, o questionário quando for respondido não carregará respostas inseridas anteriormente. Assim, o sistema abrirá um questionário novo para que você possa registrar as novas respostas no módulo.

**1 –** Para realizar essa configuração, acesse a pesquisa desejada no EPA.  Caminho: **_Portal> Pesquisas> Edite uma pesquisa_**.  

**2 –** Na aba: **informações básicas,** selecione a opção: **Responder com único usuário _(usuário geral para evitar identificação)_** _e_ _clique em **Salvar**._

Veja:

![](https://wiki.simeon.com.br/wp-content/uploads/2022/01/img_61df34a51a564.png)

**3 –** Após esta configuração a pesquisa que possui o mesmo link para todos os respondentes ou que permite o mesmo participante  responder mais de uma vez, será apresentada com o formulário “novo” para as respostas, sem o carregamento de respostas inseridas anteriormente no EPA.

> **O acesso ao formulário de respostas para participar de pesquisas poderá ser respondido várias vezes por um ou mais participantes e o EPA sempre irá registrar as novas respostas para tal.**

**4 –** Nos questionários em que esta configuração – **Responder com único usuário _(usuário geral para evitar identificação)_ _NÃO ESTIVER SELECIONADA__,_** _o sistema apresentará aos respondentes que utilizam o mesmo link ou participantes que respondam mais de uma vez esse questionário: **A ÚLTIMA RESPOSTA INSERIDA.**_
