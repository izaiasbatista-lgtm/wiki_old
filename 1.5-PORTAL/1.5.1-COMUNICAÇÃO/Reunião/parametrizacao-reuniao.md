# Reunião- Parametrização do Sistema
**![](https://wiki.simeon.com.br/wp-content/uploads/2023/05/depositphotos_38689733-stock-photo-giraffe.webp)**

**Acompanhe este artigo para entendermos cada parâmetro do sistema no módulo de reuniões.**

Parametrização- Parametrização do Sistema- Menu Reunião

-   **Configurações Avançadas de Reunião:**

1.  **Permitir Decisões por Participantes Ausentes:**
    
    É possível registrar decisões tomadas durante a reunião mesmo para os usuários que não puderam participar. Isso garante que todos os envolvidos estejam atualizados, mesmo se ausentes.
    
2.  **Registro de Decisões e Status:**
    
    As decisões tomadas durante a reunião são registradas com data e status para referência futura. Isso proporciona transparência e rastreabilidade no processo de tomada de decisões.
    
3.  **Notificações Antecipadas:**
    
    Defina a quantidade de dias antes da data da reunião para que ela seja exibida na tela principal dos usuários. Isso ajuda a garantir que todos estejam cientes das próximas reuniões com tempo suficiente para se preparar e participar.
    

| Menu | Observações | Valor |
| --- | --- | --- |
| Reuniões | Permitir criar decisão tomada para usuários que não participou da reunião | SimNão |
| Reuniões | Mostrar data e status das decisões tomadas | SimNão |
| Reuniões | Quantidade de dias antes da data da reunião para que seja exibida na tela principal dos usuários. | 8 |

-   **Observação**

Para alterarmos a parametrização de quaisquer dos itens, basta na coluna do **valor** preencher como desejar.
