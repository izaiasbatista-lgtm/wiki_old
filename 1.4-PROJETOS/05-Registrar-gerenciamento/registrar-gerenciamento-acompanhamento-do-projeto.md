# Registrar gerenciamento – Acompanhamento do projeto
Na aba Monitoramento > Acompanhamento  
Além de poder ver os acompanhamentos das tarefas, o  gestor do projeto ou o analista de projetos poderá incluir os acompanhamentos no projeto.  
Obs: O acompanhamento realizado nessas opções estarão visíveis somente para o gerente e analista de projetos.  
Para incluir clique no botão ![](https://wiki.simeon.com.br/wp-content/uploads/2020/05/img_5ed17aa6707f4.png), informe o **[tipo do acompanhamento (1)](https://wiki.simeon.com.br/configuracoes-basicas-de-projetos/),** as **horas(2), data de execução(3), descrição(4).** Caso deseje enviar email para quem não seja participante do projeto, informe em **Enviar Acompanhamento por e-mail para(5),** caso seja participante do projeto os **nomes(6)** serão listados abaixo selecione qual usuários devem receber o email.

![](https://wiki.simeon.com.br/wp-content/uploads/2020/05/img_5ed17ad3695f4.png)

Quando salvar, os acompanhamentos do projeto serão listados do lado esquerdo da tela, e os acompanhamentos das tarefas do lado direito.

![](https://wiki.simeon.com.br/wp-content/uploads/2020/05/img_5ed17be9bc2a8.png)
