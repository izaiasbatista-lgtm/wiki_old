# Abertura do Projeto – Autorizar Projeto
Quando criamos o projeto informamos na aba **Iniciação > Informações Básicas** em **Defina os papeis no projeto**,  o **Revisor** e **Aprovador** e são esses usuários que vão autorizar o andamento do novo projeto. Marcando a opção **Liberar Revisão/Aprovação** no painel do revisor/aprovador, aparecerá o cartão Projetos para que seja informada a autorização para o projeto.

![](https://wiki.simeon.com.br/wp-content/uploads/2020/05/img_5ebc4bb224bb0.png)

![](https://wiki.simeon.com.br/wp-content/uploads/2020/05/img_5ebc51353994b.png)

Clicando na caixinha de projetos será listados os projetos para revisar/aprovar, clicando no ícone de de **edição(1)** abre a tela do projeto para que o usuário faça a aprovação. Na coluna **Tipo(2)** informa se o papel do usuário no projeto, se e revisar ou aprovar.

![](https://wiki.simeon.com.br/wp-content/uploads/2020/05/img_5ebc51f758ff3.png)

Dentro do projeto o revisor/aprovador deve selecionar **Sim** ou **Não** no campo **Revisado?/Aprovado ?(3),** e caso tenha alguma observação clique no ícone **aprovação/revisão(4).** E abaixo será habilitado o campo **Observações Revisão/Aprovação(5)**, com as observações incluídas pelo  revisor e o aprovador.

![](https://wiki.simeon.com.br/wp-content/uploads/2020/05/img_5ebc5378b9216.png)
