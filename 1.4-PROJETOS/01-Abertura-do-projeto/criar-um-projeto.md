# Abertura do Projeto – Criar um projeto
-   ### **Iniciação projeto**
    

Para incluir um novo projeto, acesse o Modulo de Projetos > Gestão de projetos e clique no botão  ![](https://wiki.simeon.com.br/wp-content/uploads/2020/05/img_5ebc2e8f13b1a.png) que fica do lado direito .  
Na próxima tela informe os dados básicos de identificação do projeto, o titulo do projeto, unidade gerencial e o usuário que será o gestor do projeto.

![](https://wiki.simeon.com.br/wp-content/uploads/2020/05/img_5ebc2eef45aa1.png)

Informe os dados que caracterizam o projeto **Tipo(1)**, **Prioridade(2)**, **Categoria(3)**, **Objetivo geral do projeto(4)**, o projeto pode ser vinculado a um **Cliente(5)**, **Data Limite Conclusão Projeto(6)**, **N° Contrato/Processo(7)**, marque se o for **Projeto corporativo(8)**.

> A opção **Projeto Corporativo** é para sinalizar que o projeto é estratégico ou prioritário na organização, é possível monitorar esses projetos no relatório do modulo de planejamento.  
> Para acessar esse relatório você vai no menu **Planejamento > relatórios > Relatório Portfólio/Planos de Ação (5w2h).**

Na aba Iniciação > Informações básicas defina quais os papeis dos usuários no projeto **Gestor EPA(9)**, **G.Avaliação Final(10)**, **Quem Revisa?(11)**, **Quem aprova?(12)**.

> Para saber de todas as funcionalidades que cada papel de usuário tem no projeto acesso o artigo [**Cadastros e Permissões – Papeis e Permissões – Projetos**](https://wiki.simeon.com.br/papeis-e-permissoes-projetos/)

![](https://wiki.simeon.com.br/wp-content/uploads/2020/05/img_5ebc3b22898d8.png)

-   ### **Termo de abertura**
    

Na aba Iniciação > Termo de Abertura clique no botão **+Objetivo(13)** para incluir os objetivos específicos do seu projeto, esses objetivos específicos são os objetivos necessários atingir para que alcance o objetivo geral do seu projeto.  
Abaixo será listado os campos para cadastrar seu objetivo, informe a **Descrição do Objetivo(14), Peso(15)** e o **Resultado esperado(16).** No botão **Plano do projeto(17)** e **Termo de abertura (18)** imprime em PDF o relatório do plano do projeto e do termo de abertura.

![](https://wiki.simeon.com.br/wp-content/uploads/2020/05/img_5ebc3b850d218.png)

E abaixo pode ser preenchido as informações adicionais do projeto essas informações não são obrigatórias, mas é de suma importância para novos integrantes entenderem o projeto ou para que seja consultado sempre que haja alguma duvida durante a execução.  
O que não contempla meu projeto? Caso tenha alguma dúvida, posicione o mouse sobre o ícone ![](https://wiki.simeon.com.br/wp-content/uploads/2020/05/img_5ebc445f1fdb2.png) dos itens, abrirá uma caixa dizendo quais informações são pertinentes neste item.  
![](https://wiki.simeon.com.br/wp-content/uploads/2020/05/img_5ebc43944bd3c.png)

-   ### **Arquivos do projeto**
    

Na aba Iniciação > Arquivos você pode incluir um arquivo no projeto clicando no ícone **Adicionar Arquivos(19),** assim que o arquivo for carregado ele será listado em **Arquivos Vinculados ao Projeto(20).** Podem ser inseridas informações adicionais como A3 de projetos, cronogramas e o que mais for pertinente.Do lado direito em **Arquivos Vinculados às Tarefas(21),** pode e visualizar os arquivos vinculados as tarefas do projeto e a tarefa que esse arquivo esta anexado.

![](https://wiki.simeon.com.br/wp-content/uploads/2020/05/img_5ebc4697d7521.png)
