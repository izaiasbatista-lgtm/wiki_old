# Acompanhar Projeto – Resumo do Projeto
Em **Monitoramento** > aba **Resumo**, visualize e acompanhe os indicadores de execução do projeto.  
Aqui estão todas as informações relevantes para o Monitoramento da execução do Projeto. 

Na tabela de **Linha de Base x Cronograma Atual** traz os percentuais da execução do projeto.

-   **Linha de Base(1)** é a linha criada pelo EPA do primeiro planejamento de prazo das tarefas, pode  haver mais de uma linha de base no projeto;
-   **Cronograma Atual(2)** é o cronograma que existe hoje no projeto depois de ser ajustado;
-   **Desvio(3)**  é o percentual de desvio que o projeto teve da linha de base para o cronograma atual. 

Em todas as linhas você acompanhará o **%planejado, %conclusão, %criticidade,** na coluna do ícone **(4)** informará os percentuais do **cronograma** do projeto**,** no ícone**(5) desempenho do custo, no ícone**  **(6) o desempenho por objetivo** e no ícone **(7) o desempenho das horas**. O **Desempenho geral** do projeto levará em consideração os pesos configurados no objetivo estratégico do projeto, para saber como configurar os pesos acesse o artigo  [Planejamento Objetivos Estratégicos do Projeto .](https://wiki.simeon.com.br/02-04-objetivos-estrategicos/)

![](https://wiki.simeon.com.br/wp-content/uploads/2020/05/img_5ecd87c33e76e.png)

**⇒** O **%Criticidade** do projeto é calculado considerando a data início prevista das tarefas do projeto, será realizado da seguinte forma:

**% Previsto – % Realizado = % Criticidade**

**Obs.:** Se o resultado da criticidade for menor ou igual a zero o sistema não apresenta a criticidade no projeto.

Abaixo temos o gráfico de linha da execução do projeto, que poderá ser filtrado por **período(8) diária, semanal, mensal e anual** e também por **fase/subfase(9).  
**Nas legendas:

-   **%Planejado:** O percentual de tarefas planejadas para o período;
-   **%Projeção realizado:** são atividades previstas que sofreram atraso e estão sendo projetadas para ter uma previsão de execução do projeto;
-   **%Realizado:** as tarefas concluídas no período;
-   **Versão Automática do sistema:** linha de base criada automaticamente pelo EPA
-   **LB t:** linha de base, criada pelo gestor do projeto no decorrer do mesmo.

**\-Status Tarefas(16) –** Mostra a quantidade de tarefas pelo seu status: Concluído, Planejado, Em andamento, Em planejamento, Suspenso, Cancelado;  
**\-Status Solicitações(17) –** Mostra a quantidade de solicitações vinculadas ao projeto com seus devidos status;                  **\-Horas por tipo(18):**  
**Normal-** Quantidade de horas lançadas nas tarefas  
**Acompanhamento Projetos-** Quantidade de horas lançadas diretamente no Projeto.
