# Acompanhar Projeto – Pesquisa de projetos
Quando acessamos gestão de projetos visualizamos a tela com os filtros para pesquisar projetos.  Caso queria pesquisar os projetos que participa clique no ícone  ![](https://wiki.simeon.com.br/wp-content/uploads/2020/07/img_5efe37d1dde0b.png), se deseja pesquisar os projetos que você seja gestor do projeto clique no ícone ![](https://wiki.simeon.com.br/wp-content/uploads/2020/07/img_5efe37e85db30.png).  
E preencha os filtros conforme deseja:

![](https://wiki.simeon.com.br/wp-content/uploads/2020/07/img_5efe37c014b9d.png)

-   **Código:** Informe o código do projeto;
-   **Status:** Selecione qual o status do projeto que deseja pesquisar;
-   **Nome Projeto:** Informe o nome do projeto;
-   **Gestor:** Informe o o usuário que e o gestor do projeto;
-   **Clientes:** Informe o cliente que esta vinculado ao projeto;
-   **Ordenar por:** Selecione a forma que deseja ordenar o resultado da pesquisa: **Título, Dt. Inicio. Dt. Fim e Dt. Conclusão**;
-   **Unidade Gerencial:** Informe a unidade gerencial do projeto. Nesse filtro serão listadas as unidades estratégicas **(E)** que o usuário tem permissão;
    
    ![](https://wiki.simeon.com.br/wp-content/uploads/2020/07/img_5efe3ae026b13.png)
    
-   **Categoria:** Selecione o tipo de categoria do projeto;
-   **Status Aprovação:** Selecione o status de aprovação: **Aguardando Revisão, Projeto(s) Revisado(s), Projeto(s) Aprovado(s), Todos Projetos.** O status da aprovação e utilizado quando os projetos estão em Liberar Revisão/Aprovação .
-   **Eficácia:**  Selecione o tipo de eficácia : **Aguardando Finalização, Projeto(s) Avaliado(s), Projeto(s) Eficaz(es), Projeto(s) Não Eficaz(es)**.  A eficácia e definida no momento da finalização do projeto, onde o gestor avalia se o projeto foi eficaz.
-   **Tipo:** Selecione o tipo do projeto;
-   **Dt Inclusão:** Selecione a data da inclusão do projeto;
-   **Meus Projetos:** Caso queira consultar apenas seus projetos, marque a opção **Meus projetos;**
-   **Projeto Modelo:** Caso o projeto que for pesquisar seja um projeto modelo a opção **Projeto Modelo** precisa estar marcada.
