# Projetos – Visualização dos Arquivos do Projeto
![](https://wiki.simeon.com.br/wp-content/uploads/2022/06/Imagens-Engracado-PNG-e-Vetor_-com-Fundo-Transparente-Para-Download-Gratis-_-Pngtree-removebg-preview-164x300.png)

**Nessa versão, adicionamos uma melhoria no módulo de projetos!**

-   **Agora é possível ver de forma geral, todos os arquivos (anexos) que foram inseridos nos acompanhamentos das tarefas de projeto, na listagem de anexos da aba: Arquivos, localizado em Monitoramento dos projetos.**

-   **Com esse facilitador, você visualiza os anexos dos acompanhamentos das tarefas de seu projeto em um único lugar, não sendo necessário ter que editar/abrir cada tarefa para visualizar em seus acompanhamentos os anexos que foram inseridos.**

Veja como visualizar estes arquivos:

**1  –** Acesse um de seus projetos no EPA e na página de monitoramento, clique na aba: Arquivos.

Veja:

![](https://wiki.simeon.com.br/wp-content/uploads/2021/07/img_60eed4bb896fc.png)

**2 –** Neste local (aba **Arquivos do Projeto)**, você verá a listagem dos: **Arquivos Vinculadas aos Acompanhamentos das Tarefas.**

**2.1.** Aqui serão listados todos os arquivos que foram inseridos nos acompanhamentos das tarefas do projeto.

Se necessário, você também poderá **baixar** o arquivo e também **acessar a tarefa** de projeto que escolher a partir do link de acesso.

![](https://wiki.simeon.com.br/wp-content/uploads/2022/05/img_6287e1b76e60c.png)

Lista dos arquivos que foram inseridos nos acompanhamentos das tarefas de projeto no EPA.

**2.2.** Os arquivos que são apresentados neste ambiente são inseridos a partir dos acompanhamentos das tarefas, como mostra a imagem abaixo:

![](https://wiki.simeon.com.br/wp-content/uploads/2022/05/img_6287e38d8b459.png)

Arquivos inseridos nos acompanhamentos registrados em uma tarefa de projeto.

![](https://wiki.simeon.com.br/wp-content/uploads/2022/05/a38addc0469bb9b9bb45550042634c6d-247x300.jpg)
