# Acompanhar Projeto – Versões/Linha de Base
No decorrer do Projeto é normal realizarmos ajustes, negociarmos prazos, custos e etc. Mas é importante também termos uma comparação o que planejamos no início do projeto e como ele está sendo realizado. Para isso temos a linha de base que é uma “fotografia” do Projeto no momento atual. 

Nessa tela temos as versões do cronograma do projeto. Sempre terá a Versão automática criada pelo sistema que é gerada assim que termina de incluir as tarefas do projeto. É a sua primeira versão do cronograma do projeto.

Para incluir uma nova linha de base clique no botão ![](https://wiki.simeon.com.br/wp-content/uploads/2020/05/img_5ecee550f2977.png), informe o **responsável(1).** Marque se quer **Ativar esta linha de base como padrão ?(2).**  A linha de base padrão será utilizada na aba [**Monitoramento > Resumo**](https://wiki.simeon.com.br/04-01-resumo-do-projeto/) no gráfico **Linha Base x Cronograma atual** para calcular os percentuais na Linha de Base. E informe o **Titulo/motivo da versão(3)**.

![](https://wiki.simeon.com.br/wp-content/uploads/2020/05/img_5ecee16e88c3b.png)

Ao salvar serão listadas todas as linhas de base que tem cadastradas,  caso queira trocar a Linha base padrão e só marcar na coluna **Linha base Ativa(4).** Na coluna **versões(5)** clicando no ícone ![](https://wiki.simeon.com.br/wp-content/uploads/2020/05/img_5ecee3440c7a7.png) será carregada uma nova tela comparando a **Versão Atual do projeto**  com a **versão anterior** que selecionou .

Clicando no ícone ![](https://wiki.simeon.com.br/wp-content/uploads/2020/05/img_5ecee3d176492.png) gera um Relatório da linha de base selecionada, informando o Código Projeto, Inclusão do projeto, Gestor do Projeto, Gestor(a) de Avaliação Final, Revisor(a) e Aprovador(a).

![](https://wiki.simeon.com.br/wp-content/uploads/2020/05/img_5ecee2de307e2.png)
