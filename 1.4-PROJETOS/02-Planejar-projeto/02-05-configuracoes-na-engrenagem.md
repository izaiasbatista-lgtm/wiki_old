# Planejar Projeto – Configurações avançadas do Planejamento do Projeto (engrenagem)
![](https://wiki.simeon.com.br/wp-content/uploads/2022/05/a38addc0469bb9b9bb45550042634c6d-247x300.jpg)

Em Planejamento, temos algumas opções para configuração do seu projeto.

**PLANEJAMENTO > ENGRENAGEM ![](https://wiki.simeon.com.br/wp-content/uploads/2020/05/img_5ec82b5a37cd6.png)** 

![](https://wiki.simeon.com.br/wp-content/uploads/2022/07/img_62de9f6e79610.png)

### **ACESSO AO PROJETO**

Nessa tela permite que selecione outros usuários que não tem responsabilidades nas fases/tarefas do projeto, para conseguirem acessar e acompanhar o mesmo.

![](https://wiki.simeon.com.br/wp-content/uploads/2022/07/img_62dea02f13fb2.png)

**PERMISSÕES DE ACESSO AO PROJETO**

![](https://wiki.simeon.com.br/wp-content/uploads/2022/07/img_62dea15dd72f8.png)**Liberar Acesso para novos usuários(1)**, selecione quais usuários deseja liberar acesso.

**Liberar Acesso a Tarefas do Projeto,** a visualização é por fases, caso queira ver as tarefas clique no ícone ![](https://wiki.simeon.com.br/wp-content/uploads/2020/05/img_5ec82ea0bd07c.png) **(2)** para visualizar as tarefas e selecione quais tarefas do projeto o usuário terá acesso.

No campo**(3)** são listados todos os usuários que possuem algum acesso ao Projeto. 

**LIBERAR ACESSO A TAREFAS DO PROJETO**

![](https://wiki.simeon.com.br/wp-content/uploads/2022/07/img_62dea232886c4.png)

Para liberar o acesso a tarefa clique no ícone do cadeado ele ficará verde ![](https://wiki.simeon.com.br/wp-content/uploads/2020/05/img_5ec82db8527b7.png).

![](https://wiki.simeon.com.br/wp-content/uploads/2022/07/img_62dea2879def4.png)

para enviar e-mails dos acompanhamentos da tarefa clique no ícone da cartinha ela ficará amarela  ![](https://wiki.simeon.com.br/wp-content/uploads/2020/05/img_5ec82e113ffb3.png).

### **IMPORTAÇÃO MS PROJECT**

![](https://wiki.simeon.com.br/wp-content/uploads/2022/07/img_62dea6b424549.png)

Essa opção permite importar um arquivo do MS Project.

![](https://wiki.simeon.com.br/wp-content/uploads/2022/07/img_62dea76b28a7b.png)

**CALÉNDARIO DO PROJETO**

**Iniciação > Informações Básicas > Definir Calendário Específico do Projeto**

![](https://wiki.simeon.com.br/wp-content/uploads/2022/07/img_62deabef284c1.png)

Precisa está habilitado ![](https://wiki.simeon.com.br/wp-content/uploads/2022/07/img_62deacda00bbe.png) , para que tenha acesso ao Calendário do Projeto.

Logo após será disponibilizado a opção Calendário do Projeto

![](https://wiki.simeon.com.br/wp-content/uploads/2022/07/img_62deadcb6f5d8.png)

você poderá importar o calendário da empresa ![](https://wiki.simeon.com.br/wp-content/uploads/2020/05/img_5ecada49c29fb.png) e realizar configurações próprias do Projeto atual.

![](https://wiki.simeon.com.br/wp-content/uploads/2022/07/img_62def98054855.png)

_Por exemplo, embora a empresa trabalhe de segunda a sexta, você pode definir que apenas nas segundas irá trabalhar nesse projeto e assim por diante._ 

![](https://wiki.simeon.com.br/wp-content/uploads/2020/05/img_5ecad8614c354.png)

Informe o **titulo**, **período** e marque **trabalhar?**

Caso não trabalhe deixe desmarcado.

Do lado esquerdo  serão listadas as **exceções cadastradas(9),**  permitindo editar e excluir.

Para configurar os dias úteis marque os **dias da semana (6)** e clique em **atualizar(7)** para que o projeto calcule os prazos contabilizando apenas os dias úteis.  
Dentro desse dias úteis podem ser configurados as  exceções dos dias que  trabalha ou não trabalha, clicando em cima dos dias no **calendário(8)** abrirá uma janela para informar a exceção.

![](https://wiki.simeon.com.br/wp-content/uploads/2020/05/img_5ecad82ac84a1.png)

![](https://wiki.simeon.com.br/wp-content/uploads/2022/05/img_6294d93dc0fbc-e1653922158224-300x190.png)
